# QUENTIN WINDOW — 项目工作区

> 最后更新：2026-04-30

## 目录结构

```
quentin-window/
├── WORKFLOW.md              ← 统一工作流程（主入口）
├── README.md                ← 本文件
├── docs/                    ← 原始文档
│   ├── 项目说明.md
│   ├── 数据说明与后台规划.md
│   ├── 动效与流转说明.md
│   ├── 后期改进计划.md
│   └── 版本记录.md
├── prd/                     ← 页面级PRD
│   ├── 01-首页.md
│   ├── 02-产品中心页.md
│   ├── 03-产品详情页.md
│   ├── 04-文章详情页.md
│   ├── 05-快来尝鲜页.md
│   └── 06-购买页.md
├── prompts/                 ← AI工具提示词
│   └── v0dev-prompts.md
└── src/                     ← 项目代码（待生成）
```

## 快速开始

1. 阅读 `WORKFLOW.md` 了解整体流程
2. 阅读 `docs/` 了解项目详情
3. 阅读 `prd/` 了解每个页面的具体需求
4. 使用 `prompts/` 中的提示词生成设计稿
5. 在 `src/` 中开发项目代码
