# 版本记录

> 更新时间：2026-05-03
> 用途：记录项目关键阶段、文档收敛和重要提交节点

## 2026-05-03 首页首屏边框弱化

本轮调整：

1. 去掉首页首屏最外层容器的明显边框
2. 保留圆角与阴影，让头图更像自然展开的整张画面

本轮结果：

1. 首屏最外层不再有硬边框感
2. 头部轮播背景与页面整体过渡更柔和

## 2026-05-03 首页首屏重做

本轮调整：

1. 首页 Hero 文案按参考图重新收敛
2. 将“探索主题”模块改为首屏底部搜索框形态
3. 右侧独立图片区改为融入首屏的轮播式大画面

本轮结果：

1. 首屏更接近当前参考设计图的结构和阅读节奏
2. 轮播不再局限于一张独立卡片，而是融入整个头部画面
3. 图片区域弱化边框感，尽量营造整张画面的连续感

## 2026-05-03 全站色调校正

本轮调整：

1. 按 `docs/项目说明.md` 的设计方向重调全站基础色板
2. 将整体气质从偏冷蓝修正为暖白、平静、编辑感主导
3. 保留局部雾蓝和冷白高光，用于首页和重点交互区

本轮结果：

1. 背景、卡片、文字、边框改为更暖的中性色体系
2. 主强调色改为更克制的雾蓝，而不是偏强的冷蓝
3. 金色、亲子、游戏、实验室辅助色同步降低饱和度
4. 页面整体更接近 `hope` 文档原设定的人文与作者气质

## 2026-05-03 文档与实际流程对齐

本轮调整：

1. 将素材管理规则修正为当前实际执行方式
2. 明确外部素材直接进入 `src/assets/`
3. 删除文档中“先放 `images/` 再同步到 `public/images/`”的旧描述

本轮影响：

1. 后续素材整理、页面迁移、资源引用都以 `src/assets/` 为准
2. 文档约束与当前工程实现保持一致
