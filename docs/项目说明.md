# 项目说明

> 更新时间：2026-04-28
> 当前阶段：设计稿完成，进入文档收敛与后续还原准备阶段

## 1. 项目定位

`QUENTIN WINDOW` 是一个统一的个人窗口网站，不是单一博客，也不是单一产品官网。

项目同时承担 6 个目标：

1. 展示双 IP 形象
2. 承接 3 个核心 App 的介绍、下载与交付
3. 展示教育游戏与轻互动体验
4. 用文章中心承担 SEO 获客
5. 用“快来尝鲜”完成轻量销售与预付费验证
6. 用实验室与内测体系承接未来项目

整体定位可以概括为：

**个人品牌 + 内容站 + 产品落地页 + 游戏展示站 + MVP 验证站 + 实验项目窗口**

## 2. 当前设计方向

当前主方向不是机械复刻任意一版旧稿，而是融合多版设计优势后的统一方案：

1. 整体基调以暖白、人文感、编辑感、作者气质为主
2. 首页允许局部加入雾蓝、冷白高光，形成轻科技感
3. 产品与互动页更清爽、更具产品感，但不能走企业 SaaS 模板风
4. 亲子与游戏线更温暖柔和，但不能幼态化
5. 所有页面都应保持明亮、克制、精致、可展示的成品感

关键词：

1. 明亮
2. 暖白
3. 平静
4. 精致
5. 轻科技
6. 编辑感
7. 人文感
8. 独立开发者气质

## 4. 各页面职责边界

### 4.1 内容体系

1. 昆廷笔记：技术、成长、AI 提效、产品开发内容入口
2. 启鸣宝宝：育儿、陪伴、启蒙、亲子游戏内容入口
3. 文章中心：全站内容聚合总入口
4. 文章分类聚合页：专题、标签、主题的集合页面
5. 文章详情页：阅读、推荐与自然转化承接页

### 4.2 产品体系

1. 产品中心：3 个核心 App 的统一分发页
2. 产品详情页：成熟产品的价值、截图、场景、FAQ、下载与转化入口
3. 下载与交付中心：下载、版本、资料包、购买交付的统一服务入口

### 4.3 游戏与互动体系

1. 游戏中心：游戏展示、未来方向和轻试玩分发
2. 拼音大冒险详情页：玩法、适龄、教育价值和试玩入口
3. 下载动态墙：品牌互动装置型页面，展示热度与记忆点
4. 在线轻试玩：站内小游戏与轻互动入口

### 4.4 转化体系

1. 快来尝鲜：轻量销售入口、预付费验证中心、多类型数字商品货架
2. 购买页：单个订单承接页，负责权益、支付方式与付款说明
3. 购买成功页：付款后下一步指引页
4. 心愿单页：兴趣收集与期待管理，不承担直接销售
5. 加入社区 / 联系页：私域承接、信任建立、合作联系

### 4.5 实验室体系

1. 实验室总页：未来项目集合页
2. 实验室详情页：进度、路线、原型、目标用户与关注入口
3. 内测报名页：实验室“加入内测”的专门承接页

## 5. 关键流转

### 5.1 内容转化流

首页 -> 昆廷笔记 / 启鸣宝宝 -> 文章详情 -> 产品详情 -> 快来尝鲜 -> 购买页 -> 购买成功页 -> 加入社区

### 5.2 产品转化流

首页 -> 产品中心 -> 产品详情 -> 下载 / 心愿单 / 快来尝鲜 -> 购买页 -> 购买成功页 -> 下载与交付中心

### 5.3 游戏体验流

首页 -> 游戏中心 -> 拼音大冒险详情 -> 在线轻试玩 / 心愿单 / 育儿助手 / 快来尝鲜

### 5.4 实验室承接流

首页 -> 实验室 -> 实验室详情 -> 内测报名 / 心愿单 / 加入社区 / 快来尝鲜

### 5.5 搜索与导览流

首页搜索 -> 搜索结果页 -> 内容 / 产品 / 游戏 / 实验室详情页  
404 / 搜索空结果 -> 网站地图页 -> 对应页面

## 7. 协作与维护规则

1. 所有新文档默认使用中文
2. 项目当前以一条主线持续推进，不维护多套并行前端实现
3. 所有新素材先进入 `images/`，确认可用后再同步到 `public/images/`
4. 页面设计与前端还原均以当前收敛后的文档为准，不再以散落历史说明为准
5. 后续如需补页，优先判断是否是真正的流程断点，而不是单纯增加页面数量
