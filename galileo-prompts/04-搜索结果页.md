# 搜索结果页 — Galileo AI Prompt

```
Design a search results page for "QUENTIN WINDOW" — a personal brand website. This page shows search results across articles, products, games, and lab projects.

Style: Bright, warm, refined, editorial. Search interface should feel clean and helpful, not clinical.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accents (#B8C5D3), warm grey borders (#E8E6E1).

Page sections:

1. Search Header: Breadcrumb "首页 > 搜索结果". Large search input field, pre-filled with current query (e.g., "AI助手"). Search icon button on the right. Input has subtle focus ring with blue-grey accent.

2. Filter Tabs: Horizontal tab bar below search: 全部 | 文章 | 产品 | 游戏 | 实验室. Active tab: bottom border indicator + bold text. Inactive tabs grey, hover darkens. Click to filter by type.

3. Results List: Vertical list of result cards. Each card: type badge (文章/产品/游戏/实验室) with distinct color, title (large, linked), summary (2-3 lines with keyword highlighted), source link "来自: 文章中心 / 产品中心". Click navigates to detail page. White background, subtle border, generous padding. Hover: slight background tint + left border accent.

4. Loading State: 5 skeleton cards with animated shimmer. Each: title bar + two text lines.

5. Empty State: Friendly search icon with no results. "未找到相关内容". Suggested actions: "试试其他关键词", quick links to 产品中心, 文章中心, 快来尝鲜, 加入社区. Clean, helpful, not frustrating.

6. Hot Searches (optional): "热门搜索" title. Horizontal list of clickable keyword tags. Click fills search input and triggers search.

Max-width 1200px centered. Responsive: desktop full-width cards, tablet same with reduced padding, mobile single column with filter tabs scrolling horizontally.
```
