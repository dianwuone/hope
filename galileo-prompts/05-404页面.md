# 404页面 — Galileo AI Prompt

```
Design a 404 error page for "QUENTIN WINDOW" — a personal brand website. The page should be helpful and elegant, matching the site's refined style. NOT funny or exaggerated. Calm, refined, helpful — like a well-designed book's index page.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accents (#B8C5D3), warm grey borders (#E8E6E1).

Page sections:

1. Error Display: Centered layout. Large "404" in elegant editorial font with subtle geometric decoration or thin line art. Below: friendly message "页面不存在或已被移除". Sub-message: "试试从下面的入口找到你要的内容". Generous spacing.

2. Quick Navigation Cards: 5 cards in horizontal row (wrap on mobile): 首页 (home icon + "回到首页"), 产品中心 (grid icon + "查看产品"), 文章中心 (book icon + "阅读文章"), 快来尝鲜 (tag icon + "发现好物"), 加入社区 (people icon + "加入我们"). Each card: icon + label, white background, subtle border. Hover: lift + shadow, icon color accent. Click navigates.

3. Search Suggestion: Below cards, centered: "或者试试搜索？" with compact search input, placeholder "输入关键词...". Enter navigates to /search?q=xxx.

Responsive: desktop 5 cards in row centered, tablet 3+2 or 2+3 wrap, mobile single column stack. Mood: calm, not alarming, helpful, refined, brief.
```
