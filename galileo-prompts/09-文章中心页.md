# 文章中心页 — Galileo AI Prompt

```
Design an article center page for "QUENTIN WINDOW" — a personal brand site. This is the main content aggregation page, combining articles from both columns (昆廷笔记 and 启鸣宝宝). Note: this page is NOT in the main navigation but must be accessible via homepage, column pages, search, and breadcrumbs.

Style: Editorial, clean, content-focused. Like a premium content platform.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), dual accent colors: blue-grey (#B8C5D3) for Kunting column and warm coral (#D4A89A) for Qiming column, warm grey borders (#E8E6E1).

Page sections:

1. Page Header: Breadcrumb "首页 > 文章中心". Title "文章中心" (large, editorial). Subtitle "来自两个专栏的思考与分享".

2. Category & Tag Filter: First row: 全部 | 昆廷笔记 | 启鸣宝宝 (column filter). Second row: dynamic tag list based on selected column. Active filter: filled background + white text. Inactive: outline style. Tags change when switching columns. Smooth transition between filter states.

3. Article List: Grid layout 2 columns on desktop, 1 on mobile. Each article card: cover image (16:9), article title (bold, 18-20px), summary (2 lines), author name + published date, column badge ("昆廷笔记" blue-grey or "启鸣宝宝" coral), tags as small badges. Cards from different columns have subtle color differentiation (border or badge color). Hover: lift + shadow. Staggered fade-in.

4. Load More / Pagination: "加载更多" button at bottom. Loading indicator when fetching more. "没有更多文章了" when all loaded.

5. Loading State: 6 skeleton cards.

6. Empty State: "暂无文章" with suggestions to visit individual columns. Links to 昆廷笔记 and 启鸣宝宝.

Content organization: Default all articles sorted by date (newest first). Column filter shows only that column's articles. Tag filter further refines within column. Visual distinction between columns via color coding.

Max-width 1200px centered. Responsive: desktop 2-column grid with filters, tablet 2-column, mobile single column with horizontal filter scroll.
```
