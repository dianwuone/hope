# 文章分类聚合页 — Galileo AI Prompt

```
Design a tag-based article aggregation page for "QUENTIN WINDOW" — a personal brand site. This page groups articles by a specific tag (e.g., "AI提效", "幼小衔接", "产品开发").

Style: Clean, editorial, content-focused. Like a well-organized magazine section page.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), dual accent: blue-grey (#B8C5D3) for tech content, warm coral (#D4A89A) for parenting content, warm grey borders (#E8E6E1).

Page sections:

1. Tag Header: Breadcrumb "首页 > 文章中心 > [标签名]". Tag name as large title (e.g., "AI提效"). Tag description (1-2 lines). Article count: "共 12 篇文章". Subtle tag-specific accent color (blue-grey for tech tags, coral for parenting tags).

2. Article List: Grid layout 2 columns on desktop, 1 on mobile. Each article card: cover image (16:9), article title (bold), summary (2 lines), meta (author + date + view count), column badge "昆廷笔记" or "启鸣宝宝", other tags as small badges. White background, subtle border. Hover: lift + shadow. Staggered fade-in on scroll.

3. Related Tags Section: "相关标签" title. Horizontal list of clickable tag badges from same category/type. Click navigates to that tag's aggregation page. Each badge shows tag name.

4. Load More: "加载更多" button or pagination with loading indicator.

5. Empty State: "该标签下暂无文章" with suggestion to visit article center or browse other tags.

Max-width 1200px centered. Responsive: desktop 2-column with related tags in row, tablet 2-column, mobile single column with horizontal tag scroll.
```
