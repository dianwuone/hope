# 产品详情页 — Galileo AI Prompt

```
Design a product detail page for "QUENTIN WINDOW" — showcasing a single product called "个人助手" (Personal Assistant). The page should feel like a premium app landing page — warm, personal, not corporate. Like a well-designed Apple product page, but warmer and more personal.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accent (#B8C5D3), warm grey borders (#E8E6E1). Product-specific accent color for highlights.

Page sections:

1. Hero Section: Breadcrumb "首页 > 产品中心 > 个人助手". Left: product name (large editorial heading), one-line value proposition "你的AI个人助理", description paragraph. Right: product screenshot with device frame or shadow. CTA button "立即下载" (primary, blue-grey accent). Subtle background gradient or pattern.

2. Feature Highlights: 3-4 blocks in alternating left-right layout. Each block: feature icon (line-art style), feature title (bold, 20px), feature description (2-3 lines), feature illustration/screenshot. Alternating image-left/text-right and text-left/image-right. Scroll-triggered fade-in animation.

3. Use Cases: Title "使用场景". 2-3 horizontal cards (vertical on mobile): "工作日程管理", "育儿知识查询", "AI工具发现". Each with icon + title + description. Clean, minimal card design.

4. Screenshot Gallery: Title "预览". Horizontal scrollable gallery or carousel. Large product screenshots with device frames. Dot indicators or thumbnail navigation. Smooth scroll/swipe.

5. Version & Download: Title "版本信息". Current version number, release date, package size. Download buttons by platform (iOS/Android/Web) with icons. Release notes (collapsible, latest 3 versions). If no versions: "即将上线，敬请期待".

6. Purchase/Offer Section: Linked offer cards from "快来尝鲜" system. Price, offer description, "立即尝鲜" CTA. Subtle highlight to draw attention.

7. Related Content: Title "相关推荐". Mixed grid: related articles + related products. Article cards (smaller) + product cards (smaller). Click navigates to detail pages.

8. FAQ: Title "常见问题". Accordion/collapsible list. Each: question (clickable) → answer (expandable). Smooth expand/collapse animation. 4-6 FAQ items.

Max-width 1200px centered. Very generous whitespace. Responsive: desktop full hero with alternating feature blocks and horizontal gallery, tablet similar reduced, mobile single column stacked hero with vertical feature blocks and swipeable gallery.
```
