# 购买页 — Galileo AI Prompt

```
Design a purchase/checkout page for "QUENTIN WINDOW" — a personal brand site. Clean, trustworthy single-item checkout page. Prioritize clarity and trust — NO dark patterns, NO countdown timers, NO pressure tactics. Like a premium indie checkout — honest and straightforward.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft amber (#D4A574) for purchase elements, warm grey borders (#E8E6E1).

Max-width 800px for checkout form. Clean, focused layout.

Page sections:

1. Breadcrumb & Header: Breadcrumb "首页 > 快来尝鲜 > [商品名]". Minimal header — don't distract from purchase flow.

2. Order Summary (Left/Top): Offer name (bold, 20px). Associated project name + icon. Price large and clear (e.g., "¥29"). Benefits list (2-3 bullet points): "抢先体验资格", "优先技术支持", "终身更新". Clean, card-style layout with subtle border.

3. Order Form: Section title "购买信息". Form fields: 姓名 (text input, required), 联系方式类型 (select: 微信/邮箱/电话), 联系方式值 (text input, matches selected type). Input design: clean, generous padding, clear focus ring (blue-grey accent). Real-time validation: error messages below inputs, red border on error. Submit button "确认购买 ¥29" — full width, amber accent. Button disabled when form invalid.

4. Payment Method Selection: Section title "支付方式". Radio-style selection: 微信支付 (WeChat icon), 支付宝 (Alipay icon), 手动转账 (message icon). Selected: filled background + checkmark. Clean, visual selection cards.

5. Security & Trust: Small, subtle trust section: "🔒 支付安全说明" link + "你的信息将被安全存储，仅用于订单处理". Minimal, not intrusive.

6. FAQ (Collapsible): Section title "常见问题". Accordion: "支付后多久能收到？", "支持退款吗？", "遇到问题怎么办？"

7. Contact Author: Small section "遇到问题？联系作者" with link to /community.

Form validation: Real-time on blur. Error: red border + message below input. Success: green checkmark. Submit disabled until valid. Loading state: spinner + "处理中..."

Trust signals: Clean professional design, no countdowns, clear pricing no hidden fees, contact info visible, security note present.

Responsive: desktop two-column (summary left, form right) or stacked, tablet stacked, mobile single column full-width inputs.
```
