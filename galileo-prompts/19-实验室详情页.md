# 实验室详情页 — Galileo AI Prompt

```
Design a lab project detail page for "QUENTIN WINDOW" — a personal brand site. Showcases an experimental/in-development project, explaining its vision, progress, and how to get involved. Different from the product detail page (which is for mature products). Like a developer excitedly sharing their work-in-progress with friends.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft purple/lavender (#A89BC4) for lab elements, warm grey borders (#E8E6E1).

Max-width 1200px centered. Very generous whitespace.

Page sections:

1. Hero Section: Breadcrumb "首页 > 实验室 > 项目名". Project icon (large, subtle purple glow/aura). Project name (large, editorial). One-line description. Stage badge: idea → "想法中" (grey dashed outline), prototype → "原型中" (purple solid), beta → "内测中" (green solid). CTA buttons (dynamic by stage): idea → "加入心愿单" (outline), prototype → "加入心愿单" (outline) + "加入社区关注" (secondary), beta → "申请内测" (primary) or "快来尝鲜" (primary if offers exist). Subtle purple/lavender gradient background.

2. Project Introduction: Title "关于这个项目". Rich text content: background, goals, problems it solves. Editorial layout with comfortable reading width. Scroll-triggered fade-in.

3. Development Roadmap: Title "开发进度". Vertical timeline (left-aligned): each node has date + milestone title + brief description. Completed nodes: filled purple. Current node: pulsing indicator. Future nodes: outline/dashed. Example: "2026.01 — 想法诞生", "2026.03 — 原型设计", "2026.06 — 内测启动". Clean timeline with purple accents.

4. Prototype Preview (if available): Title "原型预览". Screenshot gallery or demo embed. Rounded corners, subtle shadow. Click to enlarge.

5. Target Users: Title "适合谁？" Brief description of target audience. Icon + text layout.

6. Get Involved: Title "参与方式". Dynamic cards by stage: "加入心愿单" — "感兴趣就加入心愿单，我们会优先通知你", "申请内测" — "成为首批体验者，帮助我们改进", "加入社区" — "关注项目动态，参与讨论". Each: icon + title + description + CTA button. Clean, inviting.

7. Community Follow: "关注实验室动态" CTA. "加入社区，第一时间了解项目进展". Button → /community.

8. FAQ: Accordion: "这个项目什么时候发布？", "如何参与内测？", "项目会收费吗？"

Mood: Exploratory, personal, forward-looking. Like a developer excitedly sharing work-in-progress. NOT corporate R&D, NOT vaporware marketing.

Responsive: desktop full layout with left-aligned timeline, tablet similar reduced, mobile single column simplified timeline.
```
