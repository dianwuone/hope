# 下载动态墙页 — Galileo AI Prompt

```
Design a "Download Activity Wall" page for "QUENTIN WINDOW" — a personal brand site. A brand engagement page that visually shows download activity in a fun, interactive way. A living wall of falling app icons. Like watching a pleasant screensaver that shows real data — fun, engaging, alive, but NOT chaotic.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accent (#B8C5D3), warm grey borders (#E8E6E1).

Page sections:

1. Page Header: Breadcrumb "首页 > 下载动态墙". Title "下载动态墙" or "看看大家都在下载什么". Subtle, doesn't compete with animation below.

2. Falling Icons Animation (Core Area): Full-width, tall section (400-600px). App/game icons fall from top with slight random horizontal offset, gentle rotation during fall, soft bounce/elastic effect on "landing" at bottom, different fall speeds. Icons accumulate at bottom creating "wall" effect. Click on falling/landed icon → navigate to product detail page. Limit active animations (max 20-30 visible), recycle off-screen. Background: very subtle gradient or pattern.

3. Statistics Bar: Below animation area. Horizontal row of stat cards: "总下载量" (large number with count-up animation), "今日下载" (number with subtle pulse on update), "最热门" (top product name + icon). Clean, minimal stat cards with subtle dividers. Numbers animate smoothly on update.

4. Category Filter (Optional): Small filter above animation: 全部 | 产品 | 游戏. Subtle, non-intrusive.

5. Product List: Below stats. Simple grid of all products: icon + name + download count. Click → product detail. Clean, static layout — the "index" of the wall.

6. CTA: "查看更多产品" button → /products. Simple, at bottom.

Technical notes: Use requestAnimationFrame or CSS animations for smooth falling. Limit concurrent animated elements. Preload icon images. Consider Canvas/WebGL for performance. Fallback: static grid if animation performance is poor.

Responsive: desktop full-width animation with horizontal stats, tablet same reduced height, mobile reduced animation area with stats stacking vertically.
```
