# 心愿单页 — Galileo AI Prompt

```
Design a wishlist page for "QUENTIN WINDOW" — a personal brand site. Lets users manage their saved/favorited projects. Personal and organized — like a personal collection list in a journal. Meaningful, not transactional.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft rose/pink (#D4A0A0) for wishlist elements, warm grey borders (#E8E6E1).

Max-width 1200px centered.

Page sections:

1. Page Header: Breadcrumb "首页 > 心愿单". Title "我的心愿单" (large, personal). Subtitle "你感兴趣的所有项目，都在这里". Total count: "共 5 个项目".

2. Status Filter: Horizontal tab bar: 全部 | 想体验 | 想下载 | 想内测 | 想购买 | 已实现. Active tab: filled background (rose accent) + white text. Inactive: outline style. Click to filter by wish_state. Smooth transition.

3. Wishlist Cards: Vertical list or grid (2 columns desktop, 1 mobile). Each card: project icon (left or top), project name (bold), project type badge (产品/游戏/实验室), current stage badge, wish state badge (want_try → "想体验" blue, want_download → "想下载" green, want_beta → "想内测" purple, want_buy → "想购买" amber, realized → "已实现" green checkmark), action buttons (change wish state, "查看详情", "移除" small subtle). White background, subtle rose border accent. Hover: lift + shadow.

4. Stats Summary: Small section showing counts by wish_state: "想体验: 2 | 想下载: 1 | 想内测: 1 | 已实现: 1". Clean, minimal display.

5. Empty State: "还没有心愿" + "去发现感兴趣的项目吧！" Quick links: 产品中心, 游戏中心, 实验室. Friendly, inviting.

6. Get Started Suggestions (if empty or few): "推荐给你" section with featured products/games. "加入心愿单" buttons.

Responsive: desktop 2-column grid, tablet 2-column, mobile single column with horizontal filter scroll.
```
