# 加入社区页 — Galileo AI Prompt

```
Design a community/contact page for "QUENTIN WINDOW" — a personal brand site. The final conversion point — where users join the community or reach out directly. Warm, trustworthy, and personal. Like a friend's "how to reach me" page. Like meeting someone at a conference and exchanging contacts — NOT corporate "contact us", NOT sales funnel.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft warm gold (#D4A574), warm grey borders (#E8E6E1).

Max-width 800px centered.

Page sections:

1. Page Header: Breadcrumb "首页 > 加入社区". Title "加入社区" or "联系我" (large, warm). Subtitle "很高兴你想了解更多，以下是联系方式". Brief, personal welcome message.

2. Community Section: Title "加入社群". WeChat group QR code (large, scannable). WeChat public account QR code. Brief description "加入微信群，获取最新动态、参与讨论、结识同好". "长按识别二维码" instruction text. Clean, centered QR code layout.

3. Contact Information: Title "直接联系". Contact cards: Email (address + "复制" button), WeChat ID (ID + "复制" button). Each: icon + info + copy action. Copy feedback: "已复制 ✓". Clean, minimal.

4. Message Form (Optional): Title "给我留言". Form fields: 来意 (radio/select: "获取最新动态" / "合作共创" / "其他事宜"), 联系方式类型 (微信/邮箱), 联系方式值 (text input), 留言 (textarea, optional). Submit button "提交" (warm gold accent). Success state: "已收到，我会尽快回复你！" Error state: clear messages. Clean, focused form design.

5. Collaboration Note: Title "合作说明". Brief note: "欢迎内容合作、产品联推、技术交流", "不接受纯广告投放". Clean, honest, direct.

6. Back to Browsing: "继续逛逛" links: 首页, 产品中心, 快来尝鲜, 实验室.

Trust signals: Real contact info, personal tone, no forms asking too much, clear purpose for each method.

Responsive: desktop centered single column with QR codes side by side, tablet same, mobile single column full-width form.
```
