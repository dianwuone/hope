# 内测报名页 — Galileo AI Prompt

```
Design a beta application page for "QUENTIN WINDOW" — a personal brand site. Collects applications for beta testing experimental projects from the lab. Exclusive but welcoming — like applying to be a beta tester for something interesting. Like being invited to try something cool — NOT corporate application, NOT exclusive to the point of cold.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft purple/lavender (#A89BC4) for lab elements, warm grey borders (#E8E6E1).

Focused layout, max-width 700px centered.

Page sections:

1. Project Info Header: Breadcrumb "首页 > 实验室 > [项目名] > 内测报名". Project icon (subtle purple glow). Project name (large). Stage badge "内测中" (green). Brief project description (2-3 lines).

2. Application Form: Title "申请内测". Intro "填写以下信息，我们会尽快审核并联系你".
   Form fields:
   - 姓名或昵称 (text, required) — placeholder "你希望我们怎么称呼你"
   - 联系方式类型 (select/radio: 微信/邮箱/电话, required)
   - 联系方式值 (text, required) — placeholder matches type
   - 城市 (text, optional) — "你在哪个城市？"
   - 申请角色 (radio group, required): "探索者" (想体验新功能), "共创者" (想参与产品改进), "家长用户" (为孩子寻找好工具), "效率用户" (想提升工作效率)
   - 场景说明 (textarea, optional) — "你最期待这个项目的哪些功能？或者你有什么建议？"
   
   Submit button "提交申请" (purple accent, full width). Disabled until required fields filled. Loading state "提交中..."

3. Process Explanation: Title "内测流程". 3-step visual: 1. "提交申请" (填写表单), 2. "审核通知" (1-3个工作日内通过微信/邮件通知), 3. "开始体验" (获得内测资格和使用指南). Clean step indicator with icons.

4. FAQ: Title "常见问题". Accordion: "内测是免费的吗？", "内测期间需要做什么？", "如何反馈问题？", "内测结束后会怎样？"

5. Submit Success State: Replace form with: animated checkmark, "已收到申请！", "我们会在1-3个工作日内通过你留下的联系方式通知结果", "加入社区，获取更多动态" CTA → /community, "返回实验室" link → /lab.

6. Contact Fallback: "有问题？直接联系" with link to /community.

Form validation: Real-time on blur. Required fields: red asterisk, error if empty. Contact value: validate format. Submit disabled until valid.

Responsive: desktop centered comfortable width, tablet same, mobile single column full-width inputs.
```
