# 下载与交付中心页 — Galileo AI Prompt

```
Design a download and delivery center page for "QUENTIN WINDOW" — a personal brand site. Unified hub for all downloads, version history, and purchase deliveries. Clean, organized, service-oriented. Like a well-designed account dashboard — helpful and clear. Everything has its place.

Color palette: Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft blue (#7BA7C9) for download elements, warm grey borders (#E8E6E1).

Max-width 1200px centered.

Page sections:

1. Page Header: Breadcrumb "首页 > 下载与交付中心". Title "下载与交付中心" (large, editorial). Subtitle "你的下载、订单和版本更新，都在这里".

2. My Orders/Deliveries Section: Title "我的订单". If orders exist: list of order cards. Each card: offer name + associated project icon, order number (small, grey), payment status badge "已支付" (green) / "待支付" (amber), delivery status badge (pending → "待交付" amber with spinner, delivered → "已交付" green with checkmark, closed → "已关闭" grey), if delivered → "下载" button (primary), if pending → "预计24小时内交付" message, if closed → "联系支持" link. If no orders: "暂无订单" + "去快来尝鲜看看？" link. Clean card-based layout.

3. Version History: Title "版本更新". List grouped by project. Each project group: project name + icon, version entries (collapsible): version number + release date + channel (stable/beta), release notes (brief), download button + package size. Expandable to show older versions. Timeline-style layout with version nodes.

4. Resource Downloads: Title "资料下载". List of downloadable resources (docs, guides). Each: resource name + description + download button + file size. Clean list layout.

5. Support: Title "需要帮助？" "遇到下载或交付问题？" message. "联系支持" button → /community. Simple, helpful.

Mood: Organized, helpful, clear. Like a well-organized toolbox — NOT cluttered, NOT overwhelming.

Responsive: desktop full layout with version history in columns, tablet similar reduced, mobile single column stacked.
```
