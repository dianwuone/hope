# 快来尝鲜页 PRD

**页面路径：** `/try`
**页面职责：** 轻量销售入口、预付费验证中心、多类型数字商品货架
**数据来源：** `offers`、`projects`

## 页面区块

### 1. 页面标题区
- **内容：** "快来尝鲜" 标题 + 副标题说明
- **数据来源：** `site_configs`

### 2. 分类筛选栏
- **内容：** 按类型筛选（全部/订阅/内测资格/数字包）
- **数据来源：** `offers.offer_type` 枚举值
- **交互：** 点击筛选，平滑过渡
- **动效：** 分类切换平滑

### 3. 商品卡片网格
- **内容：** 商品卡片列表
- **数据来源：** `offers`（sale_status='on_sale'）+ `projects`（关联项目信息）
- **展示字段：** offer_name、price_amount、price_currency、benefits_json、关联项目名和图标
- **状态标签：**
  - sale_status='on_sale' → "热卖中"
  - sale_status='sold_out' → "已售罄"
  - 即将开售 → "即将开售"
- **交互：**
  - 卡片hover：反馈清楚
  - 状态标签：一眼可识别
  - 点击卡片：进入购买页
- **动效：** 商品卡hover反馈清楚
- **禁止：** 不要用大促式夸张动画

### 4. 关联项目预览
- **内容：** 每个商品关联的项目简介
- **数据来源：** `projects`（short_desc、icon）

## 页面流转
- **入口：** 导航"快来尝鲜"、首页尝鲜横幅、产品详情页、文章详情推荐
- **出口：** 购买页（单个商品）、产品详情页、加入社区
- **面包屑：** 首页 > 快来尝鲜
