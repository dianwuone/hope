# 购买页 PRD

**页面路径：** `/try/:offerSlug`
**页面职责：** 单个订单承接页，负责权益说明、支付方式与付款
**数据来源：** `offers`、`projects`、`orders`

## 页面区块

### 1. 商品信息区
- **内容：** 商品名、价格、权益列表、关联项目
- **数据来源：** `offers`（offer_name、price_amount、price_currency、benefits_json）+ `projects`
- **交互：** 纯展示

### 2. 订单表单区
- **内容：** 购买人信息表单
- **字段：** 姓名、联系方式类型（微信/邮箱/电话）、联系方式值
- **交互：**
  - 表单focus态清晰
  - 实时校验
  - 提交按钮状态变化明确
- **动效：** 极简，安全感动效优先

### 3. 支付方式区
- **内容：** 微信支付、支付宝、手动转账（根据配置）
- **数据来源：** `site_configs`（payment_channels）
- **交互：** 选择支付方式

### 4. 安全说明区
- **内容：** 支付安全提示、隐私说明
- **交互：** 纯展示

### 5. FAQ 区
- **内容：** 购买相关常见问题
- **交互：** 折叠展开

### 6. 联系作者区
- **内容：** 遇到问题联系入口
- **数据来源：** `site_configs`
- **交互：** 点击跳转加入社区页

## 页面流转
- **入口：** 快来尝鲜商品卡片、产品详情页尝鲜入口
- **出口：** 购买成功页（提交订单后）、快来尝鲜页（返回）、加入社区
- **面包屑：** 首页 > 快来尝鲜 > 当前订单

## 特殊说明
只允许保留安全说明、FAQ、联系作者、返回快来尝鲜，不要加其他干扰元素
