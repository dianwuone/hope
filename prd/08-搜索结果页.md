# 搜索/导览结果页 PRD

**页面路径：** `/search?q=xxx`
**页面职责：** 站内搜索结果展示，帮助用户快速找到内容/产品/游戏
**数据来源：** `articles`、`projects`、`content_categories`

## 页面区块

### 1. 搜索输入区
- **内容：** 搜索框，预填当前关键词
- **交互：** 回车或点击按钮重新搜索
- **状态：** 无结果时显示空状态引导

### 2. 筛选标签栏
- **内容：** 全部 / 文章 / 产品 / 游戏 / 实验室
- **交互：** 点击切换筛选

### 3. 搜索结果列表
- **内容：** 匹配结果卡片列表
- **数据来源：** `articles`（title、summary匹配）、`projects`（project_name、short_desc匹配）
- **展示字段：** 标题、摘要、类型标签、来源页
- **交互：** 点击跳转对应详情页
- **状态：**
  - 加载：骨架屏
  - 空：显示"未找到相关内容" + 推荐入口（产品中心、文章中心、加入社区）

### 4. 热门搜索词（可选）
- **内容：** 热门搜索关键词
- **数据来源：** `analytics_events`（event_name='search'，聚合top词）
- **交互：** 点击填入搜索框

## 页面流转
- **入口：** 全站搜索框、首页搜索
- **出口：** 各详情页、产品中心、文章中心、加入社区
- **面包屑：** 首页 > 搜索结果

## 特殊说明
一期可用JSON索引搜索，后续升级为Pagefind或Algolia
