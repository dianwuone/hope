# 昆廷笔记专栏页 PRD

**页面路径：** `/columns/kunting`
**页面职责：** 技术、成长、AI提效、产品开发内容的聚合入口
**数据来源：** `articles`、`content_categories`、`content_tags`

## 页面区块

### 1. 专栏头部
- **内容：** "昆廷笔记" 标题 + 专栏简介 + 专栏封面图
- **数据来源：** `content_categories`（slug='kunting'）
- **交互：** 纯展示

### 2. 标签筛选栏
- **内容：** 该专栏下的标签列表（如：AI提效、产品开发、独立开发、技术笔记）
- **数据来源：** `content_tags`（tag_type='article'）
- **交互：** 点击筛选，切换标签过滤文章

### 3. 文章列表区
- **内容：** 文章卡片列表（瀑布流或列表）
- **数据来源：** `articles`（column_id关联昆廷笔记，status='published'，按published_at倒序）
- **展示字段：** title、cover_image、summary、published_at、view_count、like_count、标签
- **交互：**
  - 卡片hover：抬升+阴影
  - 点击：进入文章详情页
- **动效：** 文章卡hover有明确点击反馈，筛选切换有柔和过渡
- **状态：**
  - 加载：骨架屏
  - 空：提示"暂无文章"

### 4. 进入文章中心按钮
- **内容：** "查看全部文章" 入口
- **交互：** 点击跳转文章中心页

## 页面流转
- **入口：** 导航"昆廷笔记"、首页双IP入口
- **出口：** 文章详情页、文章中心、相关产品
- **面包屑：** 首页 > 昆廷笔记
