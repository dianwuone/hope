# 文章中心页 PRD

**页面路径：** `/articles`
**页面职责：** 全站内容聚合总入口
**数据来源：** `articles`、`content_categories`、`content_tags`

## 说明
文章中心不进入主导航，但必须通过以下方式可达：
1. 首页独立入口模块
2. 昆廷笔记页"进入文章中心"按钮
3. 启鸣宝宝页"进入文章中心"按钮
4. 搜索结果页跳转
5. 文章详情页面包屑返回
6. 网站地图页列出

## 页面区块

### 1. 页面标题区
- **内容：** "文章中心" 标题 + 副标题
- **数据来源：** `site_configs`

### 2. 分类筛选栏
- **内容：** 全部 / 昆廷笔记 / 启鸣宝宝 + 标签筛选
- **交互：** 点击切换筛选

### 3. 文章列表区
- **内容：** 全部文章列表
- **数据来源：** `articles`（status='published'，按published_at倒序）
- **展示字段：** title、cover_image、summary、author_name、published_at、所属专栏、标签
- **交互：** 点击进入文章详情
- **状态：** 加载骨架屏，空状态引导

### 4. 分页/加载更多
- **内容：** 分页或无限加载
- **交互：** 点击加载更多

## 页面流转
- **入口：** 首页入口、昆廷笔记/启鸣宝宝页入口、搜索页、面包屑
- **出口：** 文章详情页、昆廷笔记、启鸣宝宝
- **面包屑：** 首页 > 文章中心
