# 拼音大冒险详情页 PRD

**页面路径：** `/games/pinyin-adventure`
**页面职责：** 游戏玩法介绍、适龄说明、教育价值展示、试玩入口
**数据来源：** `projects`、`project_versions`

## 页面区块

### 1. 首屏 Hero
- **内容：** 游戏名 + 一句话描述 + 游戏主图/角色 + CTA按钮
- **数据来源：** `projects`（project_name、short_desc、cover_image）
- **CTA：** "立即试玩" / "加入心愿单" / "快来尝鲜"
- **动效：** 首屏允许轻微漂浮元素，试玩按钮反馈明显

### 2. 玩法介绍区
- **内容：** 游戏玩法说明、操作方式、关卡介绍
- **数据来源：** `projects.full_desc`
- **交互：** 纯展示

### 3. 教育价值区
- **内容：** 学习目标、适龄范围、教育理念
- **数据来源：** `projects`（target_age、full_desc）
- **交互：** 纯展示
- **动效：** 稳定阅读为主

### 4. 截图/预览区
- **内容：** 游戏截图、角色展示
- **数据来源：** `projects.full_desc`（images数组）
- **交互：** 点击放大

### 5. 相关推荐区
- **内容：** 育儿助手、亲子文章、尝鲜资格
- **数据来源：** `projects`（business_line='parenting'）+ `articles` + `offers`
- **交互：** 点击跳转
- **说明：** 导流顺序：先试玩 → 再导育儿助手 → 再导亲子文章 → 再导尝鲜资格

### 6. FAQ 区
- **内容：** 常见问题
- **交互：** 折叠展开

## 页面流转
- **入口：** 游戏中心卡片、首页游戏入口、搜索结果
- **出口：** 在线轻试玩、心愿单、育儿助手详情、快来尝鲜、亲子文章
- **面包屑：** 首页 > 游戏中心 > 拼音大冒险
