# 实验室总页 PRD

**页面路径：** `/lab`
**页面职责：** 未来项目集合页，展示实验项目和开发进度
**数据来源：** `projects`（project_type='lab'）

## 页面区块

### 1. 页面标题区
- **内容：** "实验室" 标题 + 副标题（如"探索中的未来项目"）
- **数据来源：** `site_configs`

### 2. 状态筛选栏
- **内容：** 全部 / 想法中 / 原型中 / 内测中
- **数据来源：** `projects.current_stage`（idea/prototype/beta）
- **交互：** 点击筛选

### 3. 实验项目卡片列表
- **内容：** 实验室项目卡片
- **数据来源：** `projects`（project_type='lab', status='published'）
- **展示字段：** project_name、short_desc、icon、current_stage、support_status
- **状态标签：**
  - idea → "想法中"
  - prototype → "原型中"
  - beta → "内测中"
- **交互：**
  - 状态标签切换需要清晰
  - 卡片hover有轻层级提升
  - 点击进入实验室详情页
- **动效：** 时间线与版本计划区可做轻量视口渐入

### 4. 加入社区/关注入口
- **内容：** "关注实验室动态" CTA
- **交互：** 跳转加入社区页

## 页面流转
- **入口：** 导航"实验室"、首页实验室入口
- **出口：** 实验室详情页、加入社区、心愿单
- **面包屑：** 首页 > 实验室
