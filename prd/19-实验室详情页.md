# 实验室详情页 PRD

**页面路径：** `/lab/:slug`
**页面职责：** 实验项目的进度、路线、原型、目标用户与关注入口
**数据来源：** `projects`、`beta_applications`、`wishlist_items`

## 页面区块

### 1. 首屏 Hero
- **内容：** 项目名 + 一句话描述 + 项目图标 + 状态标签 + CTA按钮
- **数据来源：** `projects`（project_name、short_desc、icon、current_stage）
- **CTA逻辑：**
  - current_stage='idea' → "加入心愿单"
  - current_stage='prototype' → "加入心愿单" + "加入社区"
  - current_stage='beta' → "申请内测" / "加入心愿单" / "快来尝鲜"
- **交互：** 按钮点击触发对应动作

### 2. 项目介绍区
- **内容：** 项目背景、目标、解决的问题
- **数据来源：** `projects.full_desc`
- **交互：** 纯展示

### 3. 开发进度/路线图区
- **内容：** 时间线形式展示开发阶段和进度
- **数据来源：** `projects.full_desc`（timeline数组）
- **交互：** 纯展示
- **动效：** 轻量视口渐入

### 4. 原型预览区（如有）
- **内容：** 原型截图或演示
- **数据来源：** `projects.full_desc`（images数组）
- **交互：** 点击放大
- **动效：** hover有轻层级提升

### 5. 目标用户区
- **内容：** 这个项目适合谁
- **数据来源：** `projects`（target_age、full_desc）

### 6. 心愿/内测/尝鲜入口
- **内容：** 根据项目阶段展示不同入口
- **交互：** 跳转内测报名页、心愿单、快来尝鲜

### 7. 加入社区引导
- **内容：** "关注项目动态" CTA
- **交互：** 跳转加入社区页

### 8. FAQ 区
- **内容：** 常见问题
- **交互：** 折叠展开

## 页面流转
- **入口：** 实验室总页卡片、首页实验室入口、搜索结果
- **出口：** 内测报名页、心愿单、加入社区、快来尝鲜
- **面包屑：** 首页 > 实验室 > 当前项目

## 特殊说明
实验室详情页负责解释开发中项目，与产品详情页（成熟产品）职责不能混用
