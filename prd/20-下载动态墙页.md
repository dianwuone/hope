# 下载动态墙页 PRD

**页面路径：** `/download-wall`
**页面职责：** 品牌互动装置型页面，展示下载热度与记忆点
**数据来源：** `analytics_events`、`projects`

## 页面区块

### 1. 页面标题区
- **内容：** "下载动态墙" 或更品牌化的标题
- **数据来源：** `site_configs`

### 2. 动态掉落区（核心区域）
- **内容：** App图标从上方掉落，落地时有轻微弹性
- **数据来源：** `analytics_events`（event_name='download_click'）+ `projects`（icon）
- **交互：** 视觉互动，点击图标可跳转产品详情
- **动效：**
  - 图标由上向下掉落
  - 落地时有轻微弹性反馈
  - 不同App/游戏使用不同掉落频率
  - 统计数字允许轻微更新动画
- **风格：** 品牌互动装置感，不是后台监控感

### 3. 统计数据区
- **内容：** 总下载量、今日下载、热门产品排行
- **数据来源：** `analytics_events`（聚合统计）
- **交互：** 纯展示
- **动效：** 数字更新微动画

### 4. 分类筛选（可选）
- **内容：** 全部 / 产品 / 游戏
- **交互：** 切换掉落内容

### 5. 导流入口
- **内容：** "查看更多产品" CTA
- **交互：** 跳转产品中心

## 页面流转
- **入口：** 首页下载动态墙入口、产品中心入口
- **出口：** 产品详情页、产品中心
- **面包屑：** 首页 > 下载动态墙
