# 心愿单页 PRD

**页面路径：** `/wishlist`
**页面职责：** 兴趣收集与期待管理，不承担直接销售
**数据来源：** `wishlist_items`、`projects`

## 页面区块

### 1. 页面标题区
- **内容：** "我的心愿单" 标题 + 简介
- **数据来源：** `site_configs`

### 2. 心愿状态筛选
- **内容：** 全部 / 想体验 / 想下载 / 想内测 / 想购买 / 已实现
- **数据来源：** `wishlist_items.wish_state`
- **交互：** 点击筛选

### 3. 心愿卡片列表
- **内容：** 已收藏的项目卡片
- **数据来源：** `wishlist_items`（visitor_id关联）+ `projects`
- **展示字段：** 项目名、图标、当前状态、心愿状态标签
- **交互：**
  - 状态切换：点击修改心愿状态
  - 取消收藏：移除心愿
  - 点击卡片：跳转项目详情页
- **动效：**
  - 收藏成功要有反馈
  - 状态切换可以轻微缩放或淡入
  - 愿望数量、状态标签更新可有微动画
- **状态：**
  - 加载：骨架屏
  - 空：显示"还没有心愿" + 引导去产品中心/实验室

### 4. 数量统计区
- **内容：** 各状态心愿数量
- **数据来源：** `wishlist_items`（聚合统计）
- **交互：** 纯展示

### 5. 上线提醒设置（二期）
- **内容：** 开启上线通知
- **交互：** 开关切换

## 页面流转
- **入口：** 辅助入口"心愿单"、各详情页"加入心愿单"操作后
- **出口：** 各项目详情页、产品中心、实验室
- **面包屑：** 首页 > 心愿单
