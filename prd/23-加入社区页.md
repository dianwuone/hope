# 加入社区/联系页 PRD

**页面路径：** `/community`
**页面职责：** 私域承接、信任建立、合作联系
**数据来源：** `community_leads`、`site_configs`

## 页面区块

### 1. 页面标题区
- **内容：** "加入社区" 或 "联系我" 标题 + 副标题
- **数据来源：** `site_configs`

### 2. 加入社区区
- **内容：** 微信群/公众号二维码、社区介绍
- **数据来源：** `site_configs`（community_wechat、community_qr_code）
- **交互：** 长按识别二维码

### 3. 联系方式区
- **内容：** 邮箱、微信、其他联系方式
- **数据来源：** `site_configs`（contact_email、contact_wechat）
- **交互：** 点击复制

### 4. 表单区（可选）
- **内容：** 留言表单（姓名、联系方式、来意、留言）
- **字段：**
  - 来意选择：latest_updates / co_create / contact_me
  - 联系方式类型：wechat / email
  - 联系方式值
  - 留言（可选）
- **交互：** 提交后保存到community_leads表
- **状态：** 提交成功/失败反馈

### 5. 合作说明区
- **内容：** 合作方向、合作方式说明
- **数据来源：** `site_configs`
- **交互：** 纯展示

## 页面流转
- **入口：** 辅助入口"加入社区"、页脚、各页面CTA
- **出口：** 返回上一页、首页
- **面包屑：** 首页 > 加入社区

## 站内互导
该页是全站转化的终点之一，不做过复杂导航
