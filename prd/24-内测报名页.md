# 内测报名页 PRD

**页面路径：** `/lab/:slug/apply`
**页面职责：** 实验室"加入内测"的专门承接页
**数据来源：** `beta_applications`、`projects`

## 页面区块

### 1. 项目信息区
- **内容：** 关联项目的名称、图标、当前阶段
- **数据来源：** `projects`
- **交互：** 纯展示

### 2. 报名表单区
- **内容：** 内测申请表单
- **字段：**
  - 姓名或昵称（必填）
  - 联系方式类型：wechat / email / phone（必填）
  - 联系方式值（必填）
  - 城市（可选）
  - 申请角色：explorer / co_creator / parent / efficiency_user（必填）
  - 场景说明（可选，text）
- **交互：**
  - 表单focus态清晰
  - 提交按钮状态变化明确
  - 实时校验
- **数据写入：** `beta_applications`（project_id、source_page='lab'、role_type、name、contact_type、contact_value、city、experience_note、status='pending'）

### 3. 说明区
- **内容：** 内测流程说明、审核周期、联系方式
- **交互：** 纯展示

### 4. FAQ 区
- **内容：** 内测相关常见问题
- **交互：** 折叠展开
- **动效：** 允许折叠展开过渡

### 5. 提交成功状态
- **内容：** "已收到申请" + 预计回复时间 + 加入社区引导
- **交互：** 跳转加入社区页

## 页面流转
- **入口：** 实验室详情页"申请内测"按钮
- **出口：** 加入社区、实验室详情页、首页
- **面包屑：** 首页 > 实验室 > 内测报名

## 特殊说明
- 一期可不做登录，直接用表单提交
- source_page字段记录来源，便于后台统计
