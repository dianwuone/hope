# 下载与交付中心页 PRD

**页面路径：** `/downloads`
**页面职责：** 下载、版本、资料包、购买交付的统一服务入口
**数据来源：** `project_versions`、`orders`、`projects`

## 页面区块

### 1. 页面标题区
- **内容：** "下载与交付中心" 标题 + 简介
- **数据来源：** `site_configs`

### 2. 我的订单/交付区
- **内容：** 已购买的订单和交付状态
- **数据来源：** `orders`（visitor_id关联）+ `offers` + `project_versions`
- **展示字段：** 商品名、订单号、支付状态、交付状态、下载链接
- **交互：**
  - 已交付：点击下载
  - 待交付：显示等待提示
  - 已关闭：显示联系入口
- **状态标签：**
  - pending → "待交付"
  - delivered → "已交付"
  - closed → "已关闭"
- **动效：** 状态标签可做轻量更新反馈

### 3. 版本列表区
- **内容：** 所有项目的版本历史
- **数据来源：** `project_versions`（status='published'）+ `projects`
- **展示字段：** 项目名、版本号、发布渠道、更新说明、发布时间
- **交互：** 点击展开查看下载链接和详细说明
- **动效：** 版本记录区适合用轻微计数或时间线过渡

### 4. 资料包下载区
- **内容：** 可下载的资料包、文档
- **数据来源：** `project_versions`（delivery_type='direct_download'）
- **交互：** 点击下载，记录埋点

### 5. 联系支持区
- **内容：** 遇到问题联系入口
- **交互：** 跳转加入社区页

## 页面流转
- **入口：** 页脚、购买成功页、产品详情页
- **出口：** 各产品详情页、加入社区
- **面包屑：** 首页 > 下载与交付中心
