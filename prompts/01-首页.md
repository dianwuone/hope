# 首页 v0.dev Prompt

## Prompt

```
Create the homepage for "QUENTIN WINDOW" — a personal brand website that serves as a content hub, product showcase, game center, and MVP validation platform. The site is built by an independent developer named Quentin.

## Design System

- **Color palette:** Warm white background (#FAFAF8 or #F8F6F1), with accents of soft blue-grey (#B8C5D3) for tech highlights. Text in deep charcoal (#2D2D2D). Subtle warm grey (#E8E6E1) for borders and dividers.
- **Typography:** Use a clean sans-serif (Inter or similar) for body. Headings should feel editorial — slightly larger, with generous letter-spacing. Chinese text should use system fonts (PingFang SC, Noto Sans SC).
- **Spacing:** Generous whitespace. Section padding 80-120px vertically. Content max-width 1200px, centered.
- **Style keywords:** Bright, warm white, calm, refined, light tech, editorial, humanistic, indie developer vibe.

## Page Structure

### 1. Hero Section
- Full-width section with warm white background
- Left side: Large headline "QUENTIN WINDOW" with a subtitle like "独立开发者的窗口 — 产品、内容与实验"
- Right side: A collage-style visual composition — layered product screenshots, app icons, and decorative geometric shapes with subtle float animation
- Primary CTA button: "探索产品" (links to /products)
- Secondary CTA: "快来尝鲜" (links to /try)
- Text enters with a staggered fade-in animation. Visual has a gentle floating effect.

### 2. Product Matrix (3-column cards)
- Section title: "核心产品" with a subtle divider
- 3 product cards side by side (stack on mobile):
  - Card 1: "个人助手" — personal productivity app
  - Card 2: "育儿助手" — parenting companion app  
  - Card 3: "AI工具助手" — AI tools collection
- Each card: product icon/illustration, product name, short description (1-2 lines), a status badge (published/beta/coming soon), and a "了解更多" link
- Card hover: lift up 4px + subtle shadow expansion
- Staggered fade-in on scroll

### 3. Quick Try Banner
- A visually distinct section with a slightly different background (very light blue-grey gradient)
- Headline: "快来尝鲜" with a tagline like "抢先体验，支持独立开发"
- Show 1-2 featured offer cards with price and a "立即尝鲜" CTA button
- Subtle glow/highlight border effect on the offer cards

### 4. Dual IP Content Section
- Two columns: "昆廷笔记" (left) and "启鸣宝宝" (right)
- Each column: column name + icon/logo, 2-3 article preview cards
- Each article card: cover image, title, summary (1 line), date
- Bottom of each column: "进入专栏 →" link
- Article cards have a clean, editorial feel with image on top, text below

### 5. Games & Interactive Section
- Section title: "游戏与互动"
- Game cards with playful but not childish design
- Primary card: "拼音大冒险" with a "在线试玩" button
- Hover: slightly more vibrant than other cards (gentle scale + color shift)

### 6. Lab Preview
- Section title: "实验室" with a "探索中..." subtitle
- 1-2 lab project cards showing experiment status badges
- Mysterious but inviting feel — slightly darker accent or gradient overlay
- "进入实验室 →" link

### 7. Community CTA
- Clean section with centered text
- "加入社区" headline with a brief description
- WeChat QR code placeholder + email link
- Simple, trust-building layout

### 8. Footer
- Site name, copyright, navigation links
- Organized in columns: 产品, 内容, 关于, 联系
- Social links / WeChat QR code
- Clean, minimal footer

## Responsive
- Desktop: full multi-column layouts
- Tablet: 2-column where applicable
- Mobile: single column, cards stack vertically, reduce section padding

## Interactions
- All cards have hover states (lift + shadow)
- CTAs have clear hover/active states
- Smooth scroll for anchor links
- Navigation bar: fixed at top, transparent on hero, solid white on scroll

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for animations
- shadcn/ui components where applicable
```
