# 产品中心页 v0.dev Prompt

## Prompt

```
Create a product center page for "QUENTIN WINDOW". This page showcases 3 core apps.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accents (#B8C5D3), warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), editorial headings with generous letter-spacing. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, section padding 80-100px, max-width 1200px centered.
- **Style:** Bright, warm, refined, editorial, light tech. Avoid generic SaaS visuals.

## Page Structure

### 1. Page Header
- Breadcrumb: 首页 > 产品中心
- Large title: "产品中心"
- Subtitle: "三个独立应用，解决真实问题"
- Clean, editorial spacing

### 2. Product Grid (3 cards)
- 3-column grid on desktop, 2 on tablet, 1 on mobile
- **Card 1: 个人助手 (Personal Assistant)**
  - App icon/illustration placeholder
  - Product name + "个人效率工具"
  - Short description: "你的AI个人助理，管理日程、整理笔记、处理邮件"
  - Status badge: "已发布" (green)
  - Action button: "获取体验" → download behavior
  - Card links to detail page on click

- **Card 2: 育儿助手 (Parenting Assistant)**
  - App icon/illustration placeholder
  - Product name + "育儿陪伴工具"
  - Short description: "AI育儿顾问，记录成长、解答疑惑、分享时光"
  - Status badge: "Beta测试" (blue)
  - Action button: "申请内测" → beta apply behavior
  - Card links to detail page on click

- **Card 3: AI工具助手 (AI Tools)**
  - App icon/illustration placeholder
  - Product name + "AI工具集合"
  - Short description: "精选AI工具合集，提升工作效率"
  - Status badge: "即将上线" (grey)
  - Action button: "加入心愿单" → wishlist behavior
  - Card links to detail page on click

- **Card design:**
  - White card with subtle border
  - Top: large icon/illustration area (aspect-ratio 16:9 or 4:3)
  - Middle: product name (large), tagline (small), description (body)
  - Bottom: status badge + action button
  - Hover: lift 4px, shadow expands, border color shifts slightly
  - Staggered fade-in on scroll

### 3. Download Activity Banner
- Light blue-grey background section
- "看看大家都在下载什么 →" link
- Links to /download-wall page
- Simple, curiosity-driven design

### 4. Empty State (if no products)
- Friendly illustration + "暂无产品，去实验室看看？"
- Links to /lab

## Responsive
- Desktop: 3-column grid with generous gaps
- Tablet: 2-column grid
- Mobile: single column, full-width cards

## Interactions
- Card hover: elevation + shadow + subtle border color change
- Action buttons: clear hover/active states with color shift
- Breadcrumb links: hover underline
- Smooth transitions between states

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for card animations
- shadcn/ui for buttons and badges
```
