# 关于页 v0.dev Prompt

## Prompt

```
Create an "About" page for "QUENTIN WINDOW". This page builds trust and helps visitors understand the person and work behind the site.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accents (#B8C5D3), warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), editorial headings. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Very generous whitespace. This page should feel like a well-designed personal essay — calm, readable, unhurried.
- **Style:** Warm, humanistic, editorial, personal. Like reading a thoughtful About page on a premium indie website.

## Page Structure

### 1. Hero / Personal Intro
- Breadcrumb: 首页 > 关于
- Large circular avatar placeholder (200px) with subtle shadow
- Name: "昆廷" (large, editorial size)
- Tagline: "内容创作者 / 产品探索者 / 终身学习者"
- Brief bio paragraph (2-3 lines): personal philosophy and what drives the projects
- Clean, centered layout with generous spacing

### 2. Core Values / Philosophy
- 3-4 value cards in a row (single column on mobile)
- Each card: icon + title + short description
- Values like: "独立创作", "真实有用", "持续迭代", "用户至上"
- Minimal, elegant card design — no heavy borders, just subtle dividers

### 3. Dual IP Introduction
- Section title: "两个内容专栏"
- Two side-by-side cards (stack on mobile):
  - **昆廷笔记**: Description of the tech/life notes column. "关于技术、思考与生活" with a "进入专栏 →" link
  - **启鸣宝宝**: Description of the parenting IP. "关于成长、陪伴与爱" with a "进入专栏 →" link
- Each card has a distinct color accent or illustration to differentiate the IPs
- Clean, editorial card design with image + text layout

### 4. Product Showcase
- Section title: "我的产品"
- 3 product mini-cards in a row
- Each: small icon, product name, one-line description, "了解详情 →" link
- Simpler than the product center page — just enough to introduce and link out

### 5. Timeline / Milestones
- Section title: "发展历程"
- Vertical timeline design (left-aligned line with nodes)
- 4-6 milestone entries:
  - Date + event title + brief description
  - Example: "2024.01 — 开始独立开发之路"
  - Example: "2024.06 — 发布个人助手 v1.0"
  - Example: "2025.01 — 昆廷笔记专栏上线"
  - Example: "2025.06 — 育儿助手 Beta 发布"
- Timeline nodes have subtle color accents
- Clean, minimal timeline design — more like a personal journal

### 6. Contact & Community
- Section title: "联系我"
- Centered layout with:
  - Email address (clickable mailto link)
  - WeChat ID with QR code placeholder
  - "加入社区" CTA button linking to /community
- Trust-building: real contact info, not just a form

### 7. Footer (reused from site)
- Standard site footer with navigation columns

## Responsive
- Desktop: multi-column layouts, large typography
- Tablet: 2-column where applicable
- Mobile: single column, reduced avatar size, timeline stays left-aligned

## Interactions
- Avatar: subtle hover scale
- Value cards: gentle hover highlight
- Timeline nodes: hover reveals more detail or highlights
- Links: clear hover states
- Smooth scroll between sections

## Content Tone
- First person ("我" / "I") — this is a personal page
- Warm but professional
- Not boastful, not humble — just real
- Chinese content with English section titles where appropriate

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for scroll animations
- shadcn/ui components
```
