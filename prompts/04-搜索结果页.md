# 搜索结果页 v0.dev Prompt

## Prompt

```
Create a search results page for "QUENTIN WINDOW" — a personal brand website. This page shows search results across articles, products, games, and lab projects.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accents (#B8C5D3), warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), editorial feel. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1200px centered.
- **Style:** Bright, warm, refined, editorial. Search interface should feel clean and helpful, not clinical.

## Page Structure

### 1. Search Header
- Breadcrumb: 首页 > 搜索结果
- Large search input field, pre-filled with current query (e.g., "AI助手")
- Search icon button on the right
- Input has a subtle focus ring with blue-grey accent
- Press Enter or click button to re-search

### 2. Filter Tabs
- Horizontal tab bar below search: 全部 | 文章 | 产品 | 游戏 | 实验室
- Active tab has a bottom border indicator + bold text
- Inactive tabs are grey, hover darkens slightly
- Click to filter results by type

### 3. Results List
- Vertical list of result cards
- Each result card:
  - Type badge (文章/产品/游戏/实验室) with distinct color
  - Title (large, linked)
  - Summary/description (2-3 lines, with keyword highlighted)
  - Source link: "来自: 文章中心 / 产品中心 / etc."
  - Click navigates to the detail page
- Card design: white background, subtle border, generous padding
- Hover: slight background tint + left border accent

### 4. Loading State
- 5 skeleton cards with animated shimmer
- Each skeleton: title bar + two text lines

### 5. Empty State
- Friendly illustration or icon (search with no results)
- "未找到相关内容"
- Suggested actions:
  - "试试其他关键词"
  - Quick links: 产品中心, 文章中心, 快来尝鲜, 加入社区
- Clean, helpful, not frustrating

### 6. Hot Searches (optional section below empty state)
- "热门搜索" title
- Horizontal list of clickable keyword tags
- Click fills the search input and triggers search

## Responsive
- Desktop: full-width result cards with comfortable spacing
- Tablet: same layout, slightly reduced padding
- Mobile: single column, filter tabs scroll horizontally if needed

## Interactions
- Search input: focus ring, clear button (×)
- Filter tabs: click to filter, active state indicator
- Result cards: hover highlight, click to navigate
- Hot search tags: click to search
- Keyboard: Enter to search, Escape to clear

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for list animations
- shadcn/ui for input, tabs, badges
```
