# 404页面 v0.dev Prompt

## Prompt

```
Create a 404 error page for "QUENTIN WINDOW". The page should be helpful and elegant, matching the site's refined style. NOT funny or exaggerated.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accents (#B8C5D3), warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), editorial feel. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, centered layout.
- **Style:** Calm, refined, helpful. Like a well-designed book's index page — not a cartoon.

## Page Structure

### 1. Error Display
- Centered layout
- Large "404" in an elegant, editorial font — not playful, not harsh. Maybe with a subtle geometric decoration or thin line art
- Below: friendly message "页面不存在或已被移除"
- Sub-message: "试试从下面的入口找到你要的内容"
- Generous spacing between elements

### 2. Quick Navigation Cards
- 5 cards in a horizontal row (wrap on mobile):
  - 首页 — home icon + "回到首页"
  - 产品中心 — grid icon + "查看产品"
  - 文章中心 — book icon + "阅读文章"
  - 快来尝鲜 — tag icon + "发现好物"
  - 加入社区 — people icon + "加入我们"
- Each card: icon + label, white background, subtle border
- Hover: lift + shadow, icon color accent
- Click navigates to the corresponding page

### 3. Search Suggestion
- Below the cards, a centered section:
- "或者试试搜索？" text
- Compact search input with placeholder "输入关键词..."
- Enter navigates to /search?q=xxx
- Clean, minimal search bar design

## Responsive
- Desktop: 5 cards in a row, centered
- Tablet: 3+2 or 2+3 wrap
- Mobile: single column stack

## Interactions
- Cards: hover lift + shadow + color shift
- Search input: focus ring, clear button
- Smooth page transitions
- Keyboard accessible: Tab through cards, Enter to navigate

## Mood
- Calm, not alarming
- Helpful, not dismissive
- Refined, matching the overall site aesthetic
- Brief — don't over-explain, just redirect

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for subtle animations
- shadcn/ui for input and cards
```
