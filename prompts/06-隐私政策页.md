# 隐私政策页 v0.dev Prompt

## Prompt

```
Create a privacy policy page for "QUENTIN WINDOW" — a personal brand website. This is a legal/policy page that should be clean, readable, and professional.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accents (#B8C5D3), warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), good line-height (1.8) for long-form reading. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Very generous line-height and paragraph spacing for comfortable reading.
- **Style:** Editorial, clean, professional. Like a well-typeset document.

## Page Structure

### 1. Header
- Breadcrumb: 首页 > 隐私政策
- Title: "隐私政策" (large, editorial)
- Last updated date: "最后更新：2026年4月30日"
- Clean, minimal header area

### 2. Table of Contents (Sidebar on desktop)
- Sticky sidebar on the left (desktop only)
- Linked section headings from the policy content
- Active section highlighted as user scrolls
- Smooth scroll on click
- On mobile: collapsible TOC at the top

### 3. Policy Content
- Full-width content area (with sidebar offset on desktop)
- Well-structured sections with clear heading hierarchy (h2, h3)
- Example sections:
  - 信息收集
  - 信息使用
  - 信息存储与保护
  - 信息共享
  - Cookie使用
  - 用户权利
  - 政策更新
  - 联系方式
- Long-form text with:
  - Comfortable line-height (1.7-1.8)
  - Paragraph spacing (1.5em between paragraphs)
  - List styling with proper indentation
  - Bold for emphasis on key terms
- Links styled with underline + color accent

### 4. Back to Top
- Floating "回到顶部" button (appears on scroll)
- Smooth scroll behavior

## Responsive
- Desktop: sidebar TOC + content area
- Tablet: collapsible TOC + full-width content
- Mobile: collapsible TOC + single column, reduced font size

## Typography Details
- h2: 24px, bold, with top border divider
- h3: 18px, semi-bold
- Body: 16px, line-height 1.8
- Lists: proper padding-left, custom bullets
- Links: blue-grey accent, underline on hover

## Interactions
- TOC links: smooth scroll to section
- Active TOC item: highlighted based on scroll position
- Back to top: smooth scroll, appears after scrolling past header
- External links: open in new tab

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for scroll-triggered TOC highlighting
- Intersection Observer for active section detection
```
