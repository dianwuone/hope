# 昆廷笔记专栏页 v0.dev Prompt

## Prompt

```
Create a column page for "昆廷笔记" (Kunting Notes) on the "QUENTIN WINDOW" site. This is a tech/life notes column — covering AI, product development, life notes, and personal growth.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accent (#B8C5D3) as the primary column color, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), editorial headings. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1200px centered.
- **Style:** Editorial, tech-forward but human. The blue-grey accent represents the "tech + thinking" vibe of this column.

## Page Structure

### 1. Column Header
- Breadcrumb: 首页 > 昆廷笔记
- Column title: "昆廷笔记" (large, editorial)
- Subtitle/description: "关于技术、思考与成长的个人笔记"
- Cover image area (wide banner, subtle gradient or abstract pattern in blue-grey tones)
- Clean, spacious header — establishes the column's identity

### 2. Tag Filter Bar
- Horizontal scrollable tag list: 全部 | AI提效 | 产品开发 | 独立开发 | 技术笔记 | 成长思考
- Active tag: filled background (blue-grey) + white text
- Inactive tags: outline style, grey text, hover darkens
- Click to filter articles by tag
- Smooth transition when switching tags

### 3. Article List
- Grid layout: 2 columns on desktop, 1 on mobile
- Each article card:
  - Cover image (aspect-ratio 16:9)
  - Article title (bold, 18-20px)
  - Summary (2 lines, grey text)
  - Meta: date + view count + like count (small, subtle)
  - Tags as small badges below the title
  - Click navigates to article detail page
- Card design: white background, subtle border, generous padding
- Hover: lift 4px + shadow expansion + subtle border color shift
- Staggered fade-in on scroll (Intersection Observer)

### 4. Loading State
- 6 skeleton cards (2-column grid)
- Each: image placeholder + title bar + two text lines + meta bar

### 5. Empty State
- "暂无文章" message
- Suggestion: "去文章中心看看？" with link to /articles

### 6. View All Articles Button
- Centered "查看全部文章 →" button at the bottom
- Links to /articles
- Outline style with blue-grey accent

## Responsive
- Desktop: 2-column article grid, full tag bar
- Tablet: 2-column grid, slightly reduced spacing
- Mobile: single column, tags scroll horizontally

## Interactions
- Tag filter: click to filter, smooth content transition
- Article cards: hover lift + shadow, click to navigate
- Scroll: staggered card reveal animation
- Breadcrumb: hover underline

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for animations
- shadcn/ui for tags, cards, badges
```
