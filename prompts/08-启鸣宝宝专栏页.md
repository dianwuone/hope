# 启鸣宝宝专栏页 v0.dev Prompt

## Prompt

```
Create a column page for "启鸣宝宝" (Qiming Baby) on the "QUENTIN WINDOW" site. This is a parenting column — covering childcare, early education,亲子 games, and family life. The style should be warm and soft, but NOT childish or cartoonish.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), warm accent color — soft coral/peach (#E8B4A2 or #D4A89A) as the column identity color, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), warm heading style. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1200px centered.
- **Style:** Warm, gentle, human, personal. Like a well-designed parenting magazine — sophisticated, not babyish.

## Page Structure

### 1. Column Header
- Breadcrumb: 首页 > 启鸣宝宝
- Column title: "启鸣宝宝" (large, editorial, warm)
- Subtitle/description: "关于成长、陪伴与爱的育儿笔记"
- Cover image area (wide banner, warm tones — soft peach/coral gradient or gentle illustration)
- The header should feel warm and inviting, but refined

### 2. Tag Filter Bar
- Horizontal scrollable tag list: 全部 | 幼小衔接 | 亲子游戏 | 启蒙教育 | 育儿心得 | 成长记录
- Active tag: filled background (warm coral/peach) + white text
- Inactive tags: outline style, grey text
- Click to filter articles
- Smooth transitions

### 3. Article List
- Grid layout: 2 columns on desktop, 1 on mobile
- Each article card:
  - Cover image (aspect-ratio 16:9)
  - Article title (bold, 18-20px)
  - Summary (2 lines, grey text)
  - Meta: date + view count + like count
  - Tags as small badges (warm color scheme)
  - Click navigates to article detail
- Card design: white background, subtle warm border, generous padding
- Hover: lift 4px + shadow + subtle warm border accent
- Staggered fade-in on scroll

### 4. Related Product Card
- A special section below the article list
- "推荐产品" title
- Product card for "育儿助手" app:
  - App icon placeholder
  - "育儿助手" name + one-line description
  - "了解详情 →" link to /products/parenting-assistant
- Card has a subtle warm gradient background to distinguish it from article cards

### 5. Loading State
- 6 skeleton cards in warm tones

### 6. Empty State
- "暂无文章" with a warm, friendly message
- Suggestion to visit article center

### 7. View All Articles Button
- Centered "查看全部文章 →" button
- Links to /articles
- Warm coral/peach accent

## Responsive
- Desktop: 2-column article grid
- Tablet: 2-column grid
- Mobile: single column, tags scroll horizontally

## Interactions
- Tag filter: smooth content transition
- Article cards: hover with warm highlight
- Product card: hover lift
- Scroll: staggered card reveal

## Mood
- Warm, gentle, personal — like a letter from a thoughtful parent
- NOT childish, NOT corporate, NOT clinical
- Sophistiated warmth

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for animations
- shadcn/ui components
```
