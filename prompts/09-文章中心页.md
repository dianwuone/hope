# 文章中心页 v0.dev Prompt

## Prompt

```
Create an article center page for "QUENTIN WINDOW" — a personal brand site. This is the main content aggregation page, combining articles from both columns (昆廷笔记 and 启鸣宝宝). Note: this page is NOT in the main navigation but must be accessible via homepage, column pages, search, and breadcrumbs.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), dual accent colors: blue-grey (#B8C5D3) for Kunting column and warm coral (#D4A89A) for Qiming column, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), editorial feel. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1200px centered.
- **Style:** Editorial, clean, content-focused. Like a premium content platform.

## Page Structure

### 1. Page Header
- Breadcrumb: 首页 > 文章中心
- Title: "文章中心" (large, editorial)
- Subtitle: "来自两个专栏的思考与分享"
- Clean, minimal header

### 2. Category & Tag Filter
- First row: 全部 | 昆廷笔记 | 启鸣宝宝 (column filter)
- Second row: dynamic tag list based on selected column
- Active filter: filled background + white text
- Inactive: outline style
- Tags change when switching columns (show relevant tags for that column)
- Smooth transition between filter states

### 3. Article List
- Grid layout: 2 columns on desktop, 1 on mobile
- Each article card:
  - Cover image (aspect-ratio 16:9)
  - Article title (bold, 18-20px)
  - Summary (2 lines)
  - Author name + published date
  - Column badge: "昆廷笔记" (blue-grey) or "启鸣宝宝" (coral)
  - Tags as small badges
  - Click navigates to article detail
- Cards from different columns have subtle color differentiation (border or badge color)
- Hover: lift + shadow
- Staggered fade-in

### 4. Load More / Pagination
- "加载更多" button at the bottom (or pagination if preferred)
- Loading indicator when fetching more
- "没有更多文章了" when all loaded

### 5. Loading State
- 6 skeleton cards

### 6. Empty State
- "暂无文章" with suggestions to visit individual columns
- Links to 昆廷笔记 and 启鸣宝宝

## Responsive
- Desktop: 2-column grid with filters
- Tablet: 2-column grid
- Mobile: single column, filters scroll horizontally

## Interactions
- Column filter: switches visible tags and articles
- Tag filter: refines within selected column
- Article cards: hover + click
- Load more: smooth append animation
- Breadcrumb: hover underline

## Content Organization
- Default: all articles sorted by date (newest first)
- Column filter: show only that column's articles
- Tag filter: further refine within column
- Visual distinction between columns via color coding

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for animations
- shadcn/ui for filters, cards, pagination
```
