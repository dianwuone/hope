# 文章分类聚合页 v0.dev Prompt

## Prompt

```
Create a tag-based article aggregation page for "QUENTIN WINDOW" — a personal brand site. This page groups articles by a specific tag (e.g., "AI提效", "幼小衔接", "产品开发").

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), dual accent: blue-grey (#B8C5D3) for tech content, warm coral (#D4A89A) for parenting content, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), editorial feel. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1200px centered.
- **Style:** Clean, editorial, content-focused. Like a well-organized magazine section page.

## Page Structure

### 1. Tag Header
- Breadcrumb: 首页 > 文章中心 > [标签名]
- Tag name as large title (e.g., "AI提效")
- Tag description (1-2 lines)
- Article count: "共 12 篇文章"
- Subtle tag-specific accent color (use blue-grey for tech tags, coral for parenting tags)
- Clean, spacious header

### 2. Article List
- Grid layout: 2 columns on desktop, 1 on mobile
- Each article card:
  - Cover image (aspect-ratio 16:9)
  - Article title (bold)
  - Summary (2 lines)
  - Meta: author + date + view count
  - Column badge: "昆廷笔记" or "启鸣宝宝"
  - Other tags as small badges
  - Click navigates to article detail
- Card design: white background, subtle border
- Hover: lift + shadow
- Staggered fade-in on scroll

### 3. Related Tags Section
- "相关标签" title
- Horizontal list of clickable tag badges
- Tags from the same category/type
- Click navigates to that tag's aggregation page
- Each tag badge shows the tag name

### 4. Load More
- "加载更多" button or pagination
- Loading indicator

### 5. Empty State
- "该标签下暂无文章"
- Suggestion to visit article center or browse other tags

## Responsive
- Desktop: 2-column grid, related tags in a row
- Tablet: 2-column grid
- Mobile: single column, tags scroll horizontally

## Interactions
- Article cards: hover + click
- Tag badges: click to navigate to other tag pages
- Load more: smooth append
- Breadcrumb: hover underline

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for animations
- shadcn/ui for cards, badges, pagination
```
