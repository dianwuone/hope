# 产品详情页 v0.dev Prompt

## Prompt

```
Create a product detail page for "QUENTIN WINDOW". This page showcases a single product (e.g., "个人助手"). The page should feel like a premium app landing page — avoid generic SaaS presentation.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accent (#B8C5D3), warm grey borders (#E8E6E1). Product-specific accent color can be used for highlights.
- **Typography:** Clean sans-serif (Inter), editorial headings. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Very generous whitespace, max-width 1200px centered.
- **Style:** Product-focused, refined, indie developer feel. Like a well-designed Apple product page, but warmer and more personal.

## Page Structure

### 1. Hero Section
- Breadcrumb: 首页 > 产品中心 > 产品名
- Left side: Product name (large, editorial), one-line value proposition, description paragraph
- Right side: Product screenshot/illustration (large, with subtle device frame or shadow)
- CTA button below the text:
  - If "已发布": "立即下载" (primary button, blue-grey accent)
  - If "Beta测试": "申请内测" (primary button)
  - If "即将上线": "加入心愿单" (outline button)
  - If "可购买": "立即尝鲜" (primary button, links to /try)
- Hero has a subtle background gradient or pattern to make it visually distinct

### 2. Feature Highlights (3-4 blocks)
- Alternating left-right layout (feature image + text)
- Each block:
  - Feature icon (simple, line-art style)
  - Feature title (bold, 20px)
  - Feature description (2-3 lines)
  - Feature illustration/screenshot
- Blocks alternate image-left/text-right and text-left/image-right
- Scroll-triggered fade-in animation

### 3. Use Cases (2-3 scenarios)
- Section title: "使用场景"
- Horizontal card row (or vertical stack on mobile)
- Each card: scenario icon + title + description
- Clean, minimal card design
- Examples: "工作日程管理", "育儿知识查询", "AI工具发现"

### 4. Screenshot Gallery
- Section title: "预览"
- Horizontal scrollable gallery or carousel
- Large product screenshots with device frames
- Dot indicators or thumbnail navigation
- Smooth scroll/swipe

### 5. Version & Download
- Section title: "版本信息"
- Current version: version number, release date, package size
- Download buttons by platform (iOS/Android/Web) with icons
- Release notes (collapsible, shows latest 3 versions)
- If no versions: "即将上线，敬请期待"

### 6. Purchase/Offer Section (if applicable)
- Linked offer cards from the "快来尝鲜" system
- Price, offer description, "立即尝鲜" CTA
- Subtle highlight to draw attention

### 7. Related Content
- Section title: "相关推荐"
- Mixed grid: related articles + related products
- Article cards (smaller) + product cards (smaller)
- Click navigates to detail pages

### 8. FAQ
- Section title: "常见问题"
- Accordion/collapsible list
- Each item: question (clickable) → answer (expandable)
- Smooth expand/collapse animation
- 4-6 FAQ items

## Responsive
- Desktop: full hero layout, alternating feature blocks, horizontal gallery
- Tablet: similar layout, slightly reduced
- Mobile: single column, stacked hero, vertical feature blocks, gallery becomes swipeable

## Interactions
- CTA button: clear hover/active states, subtle pulse for primary action
- Feature blocks: scroll-triggered fade-in
- Screenshot gallery: drag/swipe, click to enlarge
- FAQ accordion: smooth expand/collapse
- Download buttons: click records analytics event

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for scroll animations and transitions
- shadcn/ui for buttons, cards, accordion
```
