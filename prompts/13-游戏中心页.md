# 游戏中心页 v0.dev Prompt

## Prompt

```
Create a game center page for "QUENTIN WINDOW". This page showcases educational games. The design should be playful but NOT childish — sophisticated playfulness.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), playful accent — soft teal or mint (#7EC8B8) for game-related elements, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), slightly more dynamic headings for game pages. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1200px centered.
- **Style:** Playful but refined. Think: a premium indie game studio's website, not a kids' app store.

## Page Structure

### 1. Page Header
- Breadcrumb: 首页 > 游戏中心
- Title: "游戏中心" (large, editorial with a subtle playful element)
- Subtitle: "寓教于乐，探索学习的新方式"
- Clean header with a subtle game-themed decorative element (geometric, not cartoon)

### 2. Game Cards Grid
- Grid: 2 columns on desktop, 1 on mobile
- Currently: 1 game card ("拼音大冒险"), but design for scalability
- Each game card:
  - Large cover image / game illustration (aspect-ratio 16:10)
  - Game name (bold, 24px)
  - Short description (2-3 lines)
  - Target age badge: "适合 4-8 岁"
  - Status badge: "已发布" / "Beta" / "即将上线"
  - Action buttons: "了解详情" (primary) + "在线试玩" (outline, if available)
  - Click card body → game detail page
- Card design: white background, rounded corners (slightly more than other pages), subtle shadow
- Hover: lift + shadow expansion + subtle scale (1.02) — more energetic than product cards
- Staggered fade-in on scroll

### 3. Online Play Quick Access
- Section title: "在线轻试玩"
- A visually distinct section with a slightly different background (very light mint/teal)
- "无需下载，即点即玩" tagline
- 1-2 game thumbnails with "开始试玩" buttons
- Links to /play page

### 4. Empty State
- If no games published:
  - Fun but refined illustration
  - "游戏正在开发中..."
  - "去实验室看看其他项目？" link to /lab

## Responsive
- Desktop: 2-column game cards
- Tablet: 2-column, slightly reduced
- Mobile: single column, cards stack vertically

## Interactions
- Game cards: energetic hover (more than product cards, less than cartoon)
- Play button: clear hover/active with a subtle "bounce" feel
- Smooth page transitions
- Breadcrumb: hover underline

## Mood
- Playful, inviting, engaging
- NOT childish, NOT corporate
- Sophisticated playfulness — like a well-designed indie game

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for playful animations
- shadcn/ui for buttons and badges
```
