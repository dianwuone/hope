# 拼音大冒险详情页 v0.dev Prompt

## Prompt

```
Create a game detail page for "拼音大冒险" (Pinyin Adventure) on the "QUENTIN WINDOW" site. This is an educational game for children (ages 4-8) that teaches Chinese pinyin through adventure gameplay. The design should be warm and inviting but NOT cartoonish.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft teal/mint (#7EC8B8) for game elements, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), warm headings. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Very generous whitespace, max-width 1200px centered.
- **Style:** Warm, educational, inviting. Like a premium educational app's marketing page.

## Page Structure

### 1. Hero Section
- Breadcrumb: 首页 > 游戏中心 > 拼音大冒险
- Left side: Game name "拼音大冒险" (large, warm), tagline "在冒险中学习拼音，在游戏中快乐成长"
- Right side: Game character/illustration placeholder (large, with subtle float animation)
- CTA buttons:
  - "立即试玩" (primary, teal accent) — links to /play
  - "加入心愿单" (outline) — wishlist action
- Hero has a warm, inviting background (subtle gradient in teal/warm tones)

### 2. How to Play
- Section title: "怎么玩？"
- 3-4 step cards in a row:
  - Step 1: "选择关卡" — icon + description
  - Step 2: "学习拼音" — icon + description
  - Step 3: "完成挑战" — icon + description
  - Step 4: "获得奖励" — icon + description
- Each step: circular icon, step number, title, short description
- Connected by a subtle line or arrow between steps
- Clean, visual explanation of the gameplay loop

### 3. Educational Value
- Section title: "教育价值"
- 3 value cards:
  - "拼音基础" — 声母、韵母、整体认读
  - "认知发展" — 观察力、记忆力、逻辑思维
  - "学习兴趣" — 游戏化学习，激发探索欲
- Each card: icon + title + description
- Clean, informative design — not preachy

### 4. Target Age & Details
- Info section with key details:
  - 适合年龄: 4-8 岁
  - 学习内容: 拼音声母、韵母、拼读
  - 游戏时长: 每关 5-10 分钟
  - 平台: Web (在线试玩)
- Clean info grid with icons

### 5. Screenshot Gallery
- Section title: "游戏预览"
- Horizontal scrollable gallery
- Game screenshots with rounded corners and device frames
- Dot indicators for navigation

### 6. Related Recommendations
- Section title: "你可能还喜欢"
- Related cards:
  - 育儿助手 product card (since it's parenting-related)
  - Related parenting articles
  - 快来尝鲜 offer (if applicable)
- Mixed layout: product card + article cards

### 7. FAQ
- Section title: "常见问题"
- Accordion list:
  - "拼音大冒险适合几岁的孩子？"
  - "需要下载吗？"
  - "有付费内容吗？"
  - "如何记录学习进度？"
- Smooth expand/collapse

## Responsive
- Desktop: full hero layout, horizontal steps
- Tablet: similar, slightly reduced
- Mobile: single column, steps stack vertically

## Interactions
- CTA buttons: clear hover states, "试玩" button has a subtle playful effect
- Steps: scroll-triggered reveal animation
- Screenshots: swipe/drag gallery
- FAQ: smooth accordion
- Game character: subtle float animation in hero

## Mood
- Warm, inviting, educational
- NOT childish, NOT corporate
- Like a thoughtful parent recommending a good game

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for animations
- shadcn/ui for buttons, cards, accordion
```
