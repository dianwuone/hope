# 快来尝鲜页 v0.dev Prompt

## Prompt

```
Create a "快来尝鲜" (Quick Try) page for "QUENTIN WINDOW" — a personal brand site. This is a lightweight sales and pre-payment validation hub for digital products and offers. The design should be clean and trustworthy, NOT hype-driven or salesy.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft amber/gold (#D4A574) for sales elements, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), editorial feel. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1200px centered.
- **Style:** Clean, trustworthy, refined. Like a premium indie marketplace — honest pricing, no hype.

## Page Structure

### 1. Page Header
- Breadcrumb: 首页 > 快来尝鲜
- Title: "快来尝鲜" (large, editorial)
- Subtitle: "抢先体验，支持独立开发"
- Brief description: "在这里你可以获取早期体验资格、订阅服务和数字内容包"
- Clean, welcoming header

### 2. Category Filter
- Horizontal tab bar: 全部 | 订阅 | 内测资格 | 数字包
- Active tab: filled background (amber/gold accent) + white text
- Inactive tabs: outline style
- Click to filter offers by type
- Smooth transition

### 3. Offer Cards Grid
- Grid: 2-3 columns on desktop, 1 on mobile
- Each offer card:
  - Associated project icon/logo
  - Offer name (bold, 20px)
  - Price: large, clear (e.g., "¥29" or "免费")
  - Benefits list (2-3 bullet points from benefits_json)
  - Associated project name (small, linked)
  - Status badge: "热卖中" (green) / "已售罄" (grey) / "即将开售" (blue)
  - CTA button:
    - On sale: "立即尝鲜" (primary, amber accent)
    - Sold out: "已售罄" (disabled)
    - Coming soon: "敬请期待" (outline)
  - Click card → purchase page
- Card design: white background, subtle amber border accent, generous padding
- Hover: lift + shadow + subtle amber glow
- Staggered fade-in on scroll

### 4. Empty State
- If no offers available:
  - "暂无可尝鲜的内容"
  - "去产品中心看看？" link to /products

### 5. Trust Section
- Below the grid, a small trust-building section:
  - "支持独立开发" + brief message about supporting indie development
  - Simple, honest, not salesy

## Responsive
- Desktop: 2-3 column grid
- Tablet: 2-column grid
- Mobile: single column, full-width cards

## Interactions
- Category filter: smooth content transition
- Offer cards: hover with amber accent, clear CTA states
- Status badges: visually distinct for each state
- CTA buttons: clear hover/active states
- Smooth scroll animations

## Mood
- Clean, trustworthy, honest
- NOT hype-driven, NOT salesy, NOT discount-focused
- Like a friend sharing good finds — warm and genuine

## Pricing Display
- Large, clear price numbers
- Currency symbol smaller
- If free: show "免费" prominently
- If discounted: show original price (strikethrough) + new price

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for animations
- shadcn/ui for cards, badges, buttons, tabs
```
