# 购买页 v0.dev Prompt

## Prompt

```
Create a purchase/checkout page for "QUENTIN WINDOW" — a personal brand site. This is a clean, trustworthy single-item checkout page. The design should prioritize clarity and trust — NO dark patterns, NO countdown timers, NO pressure tactics.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft amber (#D4A574) for purchase elements, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), clear form typography. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Clean, focused layout. Max-width 800px for the checkout form.
- **Style:** Clean, trustworthy, focused. Like a premium indie checkout — honest and straightforward.

## Page Structure

### 1. Breadcrumb & Header
- Breadcrumb: 首页 > 快来尝鲜 > [商品名]
- Minimal header — don't distract from the purchase flow

### 2. Order Summary (Left/Top)
- Offer name (bold, 20px)
- Associated project name + icon
- Price: large, clear (e.g., "¥29")
- Benefits list (2-3 bullet points):
  - "抢先体验资格"
  - "优先技术支持"
  - "终身更新"
- Clean, card-style layout with subtle border

### 3. Order Form
- Section title: "购买信息"
- Form fields:
  - 姓名 (text input, required)
  - 联系方式类型 (select: 微信/邮箱/电话)
  - 联系方式值 (text input, matches selected type)
- Input design: clean, generous padding, clear focus ring (blue-grey accent)
- Real-time validation: error messages below inputs, red border on error
- Submit button: "确认购买 ¥29" — full width, amber accent, clear hover/active states
- Button disabled state when form invalid

### 4. Payment Method Selection
- Section title: "支付方式"
- Radio-style selection:
  - 微信支付 (with WeChat icon)
  - 支付宝 (with Alipay icon)
  - 手动转账 (with message icon)
- Selected: filled background + checkmark
- Clean, visual selection cards

### 5. Security & Trust
- Small, subtle trust section below the form:
  - "🔒 支付安全说明" link
  - "你的信息将被安全存储，仅用于订单处理"
- Minimal, not intrusive

### 6. FAQ (Collapsible)
- Section title: "常见问题"
- Accordion items:
  - "支付后多久能收到？"
  - "支持退款吗？"
  - "遇到问题怎么办？"
- Clean accordion design

### 7. Contact Author
- Small section: "遇到问题？联系作者"
- Link to /community or contact method
- Subtle, helpful

## Responsive
- Desktop: two-column (summary left, form right) or stacked
- Tablet: stacked layout
- Mobile: single column, full-width inputs

## Form Validation
- Real-time validation on blur
- Error: red border + error message below input
- Success: green checkmark
- Submit disabled until form valid
- Loading state on submit: spinner + "处理中..."

## Interactions
- Input focus: clear ring animation
- Payment method: click to select, visual feedback
- Submit button: loading state, success/error feedback
- FAQ: smooth accordion expand/collapse

## Trust Signals
- Clean, professional design
- No countdown timers or pressure
- Clear pricing with no hidden fees
- Contact information visible
- Security note present

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for form transitions
- shadcn/ui for inputs, buttons, accordion, radio group
```
