# 购买成功页 v0.dev Prompt

## Prompt

```
Create a purchase success page for "QUENTIN WINDOW" — a personal brand site. This page appears after a successful purchase, providing confirmation and next steps. The design should feel satisfying and helpful.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), success green (#6AAF7B or #7EC8B8), warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), clear typography. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Centered layout, max-width 600px.
- **Style:** Satisfying, clear, helpful. A pleasant landing after payment.

## Page Structure

### 1. Success State
- Centered layout
- Animated success icon: green checkmark with a subtle "pop" animation
- "支付成功！" (large, bold, green accent)
- Order number: "订单号: QW20260430001" (small, grey)
- Brief, warm message: "感谢你的支持，以下是下一步指引"

### 2. Next Steps (based on delivery rule)
- Section title: "下一步"
- Dynamic content based on offer's delivery_rule:

  **If auto_open (auto delivery):**
  - "权益已开通"
  - "你的体验资格已激活，点击下方按钮开始使用"
  - "开始使用" primary button → download center or product page

  **If manual_send (manual delivery):**
  - "将在24小时内发送"
  - "我们会通过微信/邮箱发送体验凭证，请留意消息"
  - "查看交付状态" button → download center

  **If invite_only:**
  - "已收到申请"
  - "我们会尽快联系你，确认体验资格"
  - "返回首页" button

- Steps appear with a staggered fade-in animation

### 3. Community CTA
- Section: "加入社区获取更多支持"
- Brief description of community benefits
- "加入社区" button → /community
- Subtle background to distinguish from other sections

### 4. Continue Browsing
- "继续逛逛" section
- Quick links:
  - "返回首页" → /
  - "继续尝鲜" → /try
  - "查看产品" → /products
- Clean link list with hover states

### 5. Fallback (no order data)
- If page accessed directly without order context:
  - "未找到订单信息"
  - "返回快来尝鲜" button → /try

## Responsive
- Desktop: centered card layout
- Tablet: same, slightly reduced padding
- Mobile: single column, full-width buttons

## Interactions
- Success icon: pop/bounce animation on page load
- Next steps: staggered reveal
- Buttons: clear hover/active states
- Links: hover underline

## Mood
- Satisfying, positive, helpful
- NOT over-the-top celebration
- A calm "well done" feeling

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for success animation and staggered reveals
- shadcn/ui for buttons and cards
```
