# 实验室总页 v0.dev Prompt

## Prompt

```
Create a lab/experiments page for "QUENTIN WINDOW". This page showcases experimental and in-development projects. The design should feel exploratory and forward-looking — a glimpse into the future.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft purple/lavender (#A89BC4 or #9B8EC4) for lab elements, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), slightly futuristic headings. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1200px centered.
- **Style:** Exploratory, forward-thinking, mysterious but inviting. Like a research lab's project showcase.

## Page Structure

### 1. Page Header
- Breadcrumb: 首页 > 实验室
- Title: "实验室" (large, editorial with a subtle experimental feel)
- Subtitle: "探索中的未来项目"
- Brief description: "这里是正在探索和开发中的项目，有些是想法，有些是原型，有些已在内测中"
- Header has a subtle purple/lavender accent or gradient

### 2. Stage Filter
- Horizontal tab bar: 全部 | 想法中 | 原型中 | 内测中
- Active tab: filled background (purple accent) + white text
- Inactive tabs: outline style
- Click to filter projects by stage
- Smooth transition

### 3. Project Cards Grid
- Grid: 2 columns on desktop, 1 on mobile
- Each project card:
  - Project icon/illustration
  - Project name (bold, 20px)
  - Short description (2-3 lines)
  - Stage badge:
    - idea → "想法中" (grey, dashed border)
    - prototype → "原型中" (purple, solid border)
    - beta → "内测中" (green, solid border)
  - Support status indicator:
    - wishlist → "加入心愿单" button
    - beta_apply → "申请内测" button
  - Click card → lab detail page
- Card design: white background, subtle purple border accent
- Hover: lift + shadow + subtle purple glow
- Staggered fade-in on scroll

### 4. Stage Timeline (optional visual)
- A horizontal timeline showing the progression: 想法 → 原型 → 内测 → 发布
- Current position marked for each project
- Subtle, informational — not interactive

### 5. Follow Lab Updates CTA
- Section title: "关注实验室动态"
- "加入社区，第一时间了解新项目"
- "加入社区" button → /community
- Subtle purple/lavender background

### 6. Empty State
- If no lab projects:
  - "实验室还在准备中..."
  - "去产品中心看看已发布的产品？" link

## Responsive
- Desktop: 2-column grid, horizontal timeline
- Tablet: 2-column grid
- Mobile: single column, timeline becomes vertical

## Interactions
- Stage filter: smooth content transition
- Project cards: hover with purple accent
- Stage badges: visually distinct for each stage
- Timeline: subtle scroll animation
- CTA: clear button states

## Mood
- Exploratory, forward-looking, intriguing
- NOT mysterious to the point of confusion
- Like peeking into a developer's workshop — exciting possibilities

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for animations
- shadcn/ui for cards, badges, buttons, tabs
```
