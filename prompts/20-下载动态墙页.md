# 下载动态墙页 v0.dev Prompt

## Prompt

```
Create a "Download Activity Wall" page for "QUENTIN WINDOW". This is an interactive page that visually shows download activity in a fun way. Think of it as a living wall of falling app icons.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), soft blue-grey accent (#B8C5D3), warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter). Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Full-width interactive area, stats below.
- **Style:** Brand engagement, playful but refined. Like a real-time data visualization, not a dashboard.

## Page Structure

### 1. Page Header
- Breadcrumb: 首页 > 下载动态墙
- Title: "下载动态墙" or "看看大家都在下载什么"
- Subtle, doesn't compete with the animation below

### 2. Falling Icons Animation (Core Area)
- **Full-width, tall section (400-600px)**
- App/game icons fall from the top of the screen with:
  - Slight random horizontal offset
  - Gentle rotation during fall
  - Soft bounce/elastic effect on "landing" at the bottom
  - Different fall speeds for variety
- Icons accumulate at the bottom, creating a "wall" effect
- Click on a falling/landed icon → navigate to that product's detail page
- **Performance:** Limit active animations (max 20-30 visible icons), recycle off-screen ones
- Background: very subtle gradient or pattern

### 3. Statistics Bar
- Below the animation area
- Horizontal row of stat cards:
  - "总下载量" — large number with count-up animation
  - "今日下载" — number with subtle pulse on update
  - "最热门" — top product name + icon
- Clean, minimal stat cards with subtle dividers
- Numbers animate smoothly when they update

### 4. Category Filter (Optional)
- Small filter above the animation: 全部 | 产品 | 游戏
- Click to filter which icons appear in the animation
- Subtle, non-intrusive

### 5. Product List
- Below stats, a simple grid of all products with:
  - Icon + name + download count
  - Click → product detail page
- Clean, static layout — the "index" of the wall

### 6. CTA
- "查看更多产品" button → /products
- Simple, at the bottom

## Responsive
- Desktop: full-width animation, horizontal stats
- Tablet: same, slightly reduced height
- Mobile: reduced animation area, stats stack vertically

## Technical Notes
- Use requestAnimationFrame or CSS animations for smooth falling
- Limit concurrent animated elements for performance
- Preload icon images
- Consider using Canvas or WebGL for smoother animation if many icons
- Fallback: static grid of icons if animation performance is poor

## Interactions
- Falling icons: continuous animation
- Click on icon: navigate to product
- Stats: count-up animation on load, smooth number transitions
- Category filter: changes which icons fall

## Mood
- Fun, engaging, alive
- NOT chaotic, NOT distracting
- Like watching a pleasant screensaver that happens to show real data

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion or CSS animations for falling effect
- Canvas API (optional, for performance)
- shadcn/ui for stats and filter
```
