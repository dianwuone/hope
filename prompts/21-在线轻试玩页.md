# 在线轻试玩页 v0.dev Prompt

## Prompt

```
Create an online play/trial page for "QUENTIN WINDOW" — a personal brand site. This page hosts lightweight browser-based games that users can play directly. Currently features "拼音大冒险" (Pinyin Adventure) as the primary game.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft teal/mint (#7EC8B8) for game elements, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter). Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Game area is the focus, with minimal distractions around it.
- **Style:** Clean, focused on gameplay. Like a well-designed web game portal.

## Page Structure

### 1. Game Selection (if multiple games)
- Horizontal tab or card selector at the top
- Each game: icon + name + "开始游戏" button
- Active game highlighted
- Currently: just "拼音大冒险"

### 2. Game Area (Main Section)
- **Large, centered game area (responsive, max 800x600 or similar)**
- Contains:
  - Start screen: game title + "开始游戏" button + brief instructions
  - Gameplay area: the actual game (placeholder for now)
  - Game over screen: score + "再玩一次" + "查看排行榜"
- Game area has a subtle border/shadow to frame it
- Rounded corners

### 3. Score & Status Bar
- Below the game area
- Current score (large, animated number)
- Best score (personal record)
- Game status: "游戏中" / "已结束" / "准备开始"
- Clean, minimal bar

### 4. Leaderboard
- Section title: "排行榜"
- Table or card list:
  - Rank + nickname + score + date
  - Top 3 highlighted with special badges (🥇🥈🥉)
  - Current player's rank highlighted if on the list
- Clean table design
- If no scores yet: "还没有记录，成为第一个！"

### 5. Related Recommendations
- Section title: "你可能还喜欢"
- Cards for:
  - 游戏详情页 link ("了解更多关于拼音大冒险")
  - 育儿助手 product card
  - 快来尝鲜 offer (if applicable)
- Clean, minimal layout below the game

## Game Design Notes (for the placeholder)
- Simple, clean game UI
- Large, touch-friendly buttons
- Clear feedback on actions (correct/wrong)
- Score counter with animation
- Sound toggle button (muted by default)
- Not too complex — this is a lightweight trial, not a full game

## Responsive
- Desktop: centered game area, leaderboard beside or below
- Tablet: similar, slightly reduced
- Mobile: full-width game area, leaderboard below, touch-optimized controls

## Interactions
- Start button: game begins
- Gameplay: interactive (placeholder for actual game logic)
- Score: animated counter
- Leaderboard: hover rows, click to view profile (if applicable)
- Game over: smooth transition to results

## Mood
- Fun, inviting, engaging
- NOT childish, NOT overwhelming
- A pleasant way to spend 5-10 minutes

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for UI animations
- HTML5 Canvas or DOM-based game engine (placeholder)
- shadcn/ui for leaderboard and cards
```
