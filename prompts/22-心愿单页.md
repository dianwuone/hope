# 心愿单页 v0.dev Prompt

## Prompt

```
Create a wishlist page for "QUENTIN WINDOW". This page lets users manage their saved/favorited projects. The design should feel personal and organized — like a personal collection.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft rose/pink (#D4A0A0) for wishlist elements, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), personal feel. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1200px centered.
- **Style:** Personal, organized, warm. Like a well-kept personal collection list.

## Page Structure

### 1. Page Header
- Breadcrumb: 首页 > 心愿单
- Title: "我的心愿单" (large, personal)
- Subtitle: "你感兴趣的所有项目，都在这里"
- Total count: "共 5 个项目"

### 2. Status Filter
- Horizontal tab bar: 全部 | 想体验 | 想下载 | 想内测 | 想购买 | 已实现
- Active tab: filled background (rose accent) + white text
- Inactive tabs: outline style
- Click to filter by wish_state
- Smooth transition

### 3. Wishlist Cards
- Vertical list or grid (2 columns desktop, 1 mobile)
- Each card:
  - Project icon (left or top)
  - Project name (bold)
  - Project type badge: 产品 / 游戏 / 实验室
  - Current stage badge
  - Wish state badge:
    - want_try → "想体验" (blue)
    - want_download → "想下载" (green)
    - want_beta → "想内测" (purple)
    - want_buy → "想购买" (amber)
    - realized → "已实现" (green, checkmark)
  - Action buttons:
    - Change wish state (dropdown or toggle)
    - "查看详情" → project detail page
    - "移除" (small, subtle)
  - Click card body → project detail page
- Card design: white background, subtle rose border accent
- Hover: lift + shadow

### 4. Stats Summary
- Small section showing counts by wish_state:
  - "想体验: 2 | 想下载: 1 | 想内测: 1 | 已实现: 1"
- Clean, minimal display

### 5. Empty State
- "还没有心愿"
- "去发现感兴趣的项目吧！"
- Quick links: 产品中心, 游戏中心, 实验室
- Friendly, inviting

### 6. Get Started Suggestions (if empty or few items)
- "推荐给你" section with featured products/games
- "加入心愿单" buttons on each

## Responsive
- Desktop: 2-column grid, filter bar full
- Tablet: 2-column grid
- Mobile: single column, filter scrolls horizontally

## Interactions
- Status filter: smooth content transition
- Wish state change: animation (badge color change, subtle scale)
- Remove: swipe-to-delete on mobile, click X on desktop
- Card hover: lift + shadow
- Empty state: friendly animation

## Mood
- Personal, organized, warm
- Like a wish list in a journal — meaningful, not transactional

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for animations
- shadcn/ui for cards, badges, buttons, tabs
```
