# 加入社区页 v0.dev Prompt

## Prompt

```
Create a community/contact page for "QUENTIN WINDOW" — a personal brand site. This is the final conversion point — where users join the community or reach out directly. The design should be warm, trustworthy, and personal.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft warm gold (#D4A574), warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), warm, personal. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 800px centered.
- **Style:** Warm, personal, trustworthy. Like a friend's "how to reach me" page.

## Page Structure

### 1. Page Header
- Breadcrumb: 首页 > 加入社区
- Title: "加入社区" or "联系我" (large, warm)
- Subtitle: "很高兴你想了解更多，以下是联系方式"
- Brief, personal welcome message

### 2. Community Section
- Section title: "加入社群"
- WeChat group QR code (large, scannable)
- WeChat public account QR code
- Brief description: "加入微信群，获取最新动态、参与讨论、结识同好"
- "长按识别二维码" instruction text
- Clean, centered QR code layout

### 3. Contact Information
- Section title: "直接联系"
- Contact cards:
  - Email: address + "复制" button
  - WeChat ID: ID + "复制" button
- Each card: icon + info + copy action
- Copy feedback: "已复制 ✓"
- Clean, minimal design

### 4. Message Form (Optional)
- Section title: "给我留言"
- Form fields:
  - 来意 (radio/select):
    - "获取最新动态"
    - "合作共创"
    - "其他事宜"
  - 联系方式类型: 微信 / 邮箱
  - 联系方式值 (text input)
  - 留言 (textarea, optional)
- Submit button: "提交" (warm gold accent)
- Success state: "已收到，我会尽快回复你！"
- Error state: clear error messages
- Clean, focused form design

### 5. Collaboration Note
- Section title: "合作说明"
- Brief note about collaboration opportunities:
  - "欢迎内容合作、产品联推、技术交流"
  - "不接受纯广告投放"
- Clean, honest, direct

### 6. Back to Browsing
- "继续逛逛" links:
  - 首页, 产品中心, 快来尝鲜, 实验室
- Simple link list

## Responsive
- Desktop: centered single column, QR codes side by side
- Tablet: same
- Mobile: single column, full-width form

## Interactions
- Copy buttons: click → copy → "已复制 ✓" feedback
- QR codes: long-press to scan (mobile) or hover to enlarge
- Form: real-time validation, submit loading state
- Success state: smooth transition

## Trust Signals
- Real contact information
- Personal tone
- No forms that ask for too much
- Clear purpose for each contact method

## Mood
- Warm, welcoming, genuine
- Like meeting someone at a conference and exchanging contacts
- NOT corporate "contact us", NOT sales funnel

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for form transitions
- shadcn/ui for inputs, buttons, radio group
```
