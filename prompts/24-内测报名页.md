# 内测报名页 v0.dev Prompt

## Prompt

```
Create a beta application page for "QUENTIN WINDOW". This page collects applications for beta testing experimental projects from the lab. The design should feel exclusive but welcoming — like applying to be a beta tester for something interesting.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft purple/lavender (#A89BC4) for lab elements, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter). Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Focused layout, max-width 700px centered.
- **Style:** Exclusive but friendly. Like being invited to try something special.

## Page Structure

### 1. Project Info Header
- Breadcrumb: 首页 > 实验室 > [项目名] > 内测报名
- Project icon (with subtle purple glow)
- Project name (large)
- Current stage badge: "内测中" (green)
- Brief project description (2-3 lines)
- Clean, focused header

### 2. Application Form
- Section title: "申请内测"
- Brief intro: "填写以下信息，我们会尽快审核并联系你"

- Form fields:
  - **姓名或昵称** (text input, required)
    - Placeholder: "你希望我们怎么称呼你"
  
  - **联系方式类型** (select/radio: 微信 / 邮箱 / 电话, required)
  
  - **联系方式值** (text input, required)
    - Placeholder matches selected type
  
  - **城市** (text input, optional)
    - Placeholder: "你在哪个城市？"
  
  - **申请角色** (radio group, required):
    - "探索者" — 我想体验新功能
    - "共创者" — 我想参与产品改进
    - "家长用户" — 我为孩子寻找好工具
    - "效率用户" — 我想提升工作效率
  
  - **场景说明** (textarea, optional)
    - Placeholder: "你最期待这个项目的哪些功能？或者你有什么建议？"

- Submit button: "提交申请" (purple accent, full width)
- Button disabled until required fields filled
- Loading state on submit: "提交中..."

### 3. Process Explanation
- Section title: "内测流程"
- 3-step visual:
  1. "提交申请" — 填写表单
  2. "审核通知" — 1-3个工作日内通过微信/邮件通知
  3. "开始体验" — 获得内测资格和使用指南
- Clean step indicator with icons

### 4. FAQ
- Section title: "常见问题"
- Accordion items:
  - "内测是免费的吗？"
  - "内测期间需要做什么？"
  - "如何反馈问题？"
  - "内测结束后会怎样？"
- Smooth expand/collapse

### 5. Submit Success State
- Replace form with:
  - Success icon (animated checkmark)
  - "已收到申请！"
  - "我们会在1-3个工作日内通过你留下的联系方式通知结果"
  - "加入社区，获取更多动态" CTA → /community
  - "返回实验室" link → /lab

### 6. Contact Fallback
- Small section: "有问题？直接联系"
- Link to /community

## Form Validation
- Real-time on blur
- Required fields: red asterisk, error message if empty
- Contact value: validate format based on type (email format, phone format)
- Submit disabled until valid
- Loading state during submission

## Responsive
- Desktop: centered form, comfortable width
- Tablet: same
- Mobile: single column, full-width inputs

## Interactions
- Form inputs: clear focus ring (purple accent)
- Role selection: visual radio cards with icons
- Submit: loading → success transition
- FAQ: accordion
- Steps: scroll-triggered reveal

## Mood
- Exclusive but welcoming
- Like being invited to try something cool
- NOT corporate application, NOT exclusive to the point of cold

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for form and success transitions
- shadcn/ui for inputs, radio, select, accordion, buttons
```
