# 下载与交付中心页 v0.dev Prompt

## Prompt

```
Create a download and delivery center page for "QUENTIN WINDOW". This is the unified hub for all downloads, version history, and purchase deliveries. The design should be organized and service-oriented.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), accent: soft blue (#7BA7C9) for download elements, warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), clear, functional. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1200px centered.
- **Style:** Clean, organized, service-oriented. Like a well-designed account dashboard — helpful and clear.

## Page Structure

### 1. Page Header
- Breadcrumb: 首页 > 下载与交付中心
- Title: "下载与交付中心" (large, editorial)
- Subtitle: "你的下载、订单和版本更新，都在这里"

### 2. My Orders/Deliveries Section
- Section title: "我的订单"
- If orders exist: list of order cards
  - Each card:
    - Offer name + associated project icon
    - Order number (small, grey)
    - Payment status badge: "已支付" (green) / "待支付" (amber)
    - Delivery status badge:
      - pending → "待交付" (amber, with spinner icon)
      - delivered → "已交付" (green, with checkmark)
      - closed → "已关闭" (grey)
    - If delivered: "下载" button (primary)
    - If pending: "预计24小时内交付" message
    - If closed: "联系支持" link
- If no orders: "暂无订单" + "去快来尝鲜看看？" link
- Clean, card-based layout

### 3. Version History
- Section title: "版本更新"
- List grouped by project
- Each project group:
  - Project name + icon
  - Version entries (collapsible):
    - Version number + release date + channel (stable/beta)
    - Release notes (brief)
    - Download button + package size
  - Expandable to show older versions
- Timeline-style layout with version nodes
- Clean, organized

### 4. Resource Downloads
- Section title: "资料下载"
- List of downloadable resources (docs, guides, etc.)
- Each: resource name + description + download button + file size
- Clean, list layout

### 5. Support
- Section title: "需要帮助？"
- "遇到下载或交付问题？" message
- "联系支持" button → /community
- Simple, helpful

## Responsive
- Desktop: full layout, version history in columns
- Tablet: similar, slightly reduced
- Mobile: single column, version history stacked

## Interactions
- Download buttons: click → download + analytics event
- Version history: expand/collapse older versions
- Order cards: hover highlight
- Status badges: clear visual distinction

## Mood
- Organized, helpful, clear
- Like a well-organized toolbox — everything has its place
- NOT cluttered, NOT overwhelming

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Framer Motion for expand/collapse animations
- shadcn/ui for cards, badges, buttons, accordion
```
