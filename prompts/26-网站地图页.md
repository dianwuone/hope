# 网站地图页 v0.dev Prompt

## Prompt

```
Create a sitemap page for "QUENTIN WINDOW" — a personal brand site. This page provides a complete overview of all pages on the site, organized by category. It serves both users and search engines.

## Design System

- **Color palette:** Warm white background (#FAFAF8), deep charcoal text (#2D2D2D), warm grey borders (#E8E6E1).
- **Typography:** Clean sans-serif (Inter), clear hierarchy. Chinese: PingFang SC, Noto Sans SC.
- **Spacing:** Generous whitespace, max-width 1000px centered.
- **Style:** Clean, organized, functional. Like a well-structured book index.

## Page Structure

### 1. Page Header
- Breadcrumb: 首页 > 网站地图
- Title: "网站地图" (large, editorial)
- Subtitle: "全站页面一览"

### 2. Category Sections
- Grid of category cards (2-3 columns on desktop)
- Each category:

  **内容 (Content)**
  - 文章中心 → /articles
  - 昆廷笔记 → /columns/kunting
  - 启鸣宝宝 → /columns/qiming

  **产品 (Products)**
  - 产品中心 → /products
  - 个人助手 → /products/personal-assistant
  - 育儿助手 → /products/parenting-assistant
  - AI工具助手 → /products/ai-tools

  **游戏 (Games)**
  - 游戏中心 → /games
  - 拼音大冒险 → /games/pinyin-adventure
  - 在线轻试玩 → /play

  **销售 (Sales)**
  - 快来尝鲜 → /try
  - 下载与交付中心 → /downloads

  **实验室 (Lab)**
  - 实验室 → /lab
  - 内测报名 → /lab/apply

  **社区 (Community)**
  - 心愿单 → /wishlist
  - 加入社区 → /community

  **关于 (About)**
  - 关于 → /about
  - 隐私政策 → /privacy

- Each category card:
  - Category name (bold, with icon)
  - List of page links
  - Each link: page name → clickable, navigates to the page
  - Hover: underline + color accent

### 3. Browse by Goal (Optional)
- Section title: "按目标浏览"
- Horizontal row of goal cards:
  - "我想下载App" → 产品中心
  - "我想看文章" → 文章中心
  - "我想加入内测" → 实验室
  - "我想尝鲜购买" → 快来尝鲜
  - "我想联系作者" → 加入社区
- Each card: icon + goal text + arrow
- Click navigates to relevant page
- Clean, visual, helpful

## Responsive
- Desktop: 2-3 column grid for categories
- Tablet: 2-column grid
- Mobile: single column

## Interactions
- All links: hover underline + color accent
- Goal cards: hover lift + shadow
- Smooth page transitions

## SEO Notes
- This page helps search engines discover all pages
- All links should be standard <a> tags (not just JS navigation)
- Consider adding structured data (ItemList schema)

## Mood
- Clean, organized, helpful
- Like a well-organized directory
- NOT cluttered, NOT overwhelming

## Tech Stack
- Next.js App Router
- Tailwind CSS
- shadcn/ui for cards
```
